# 案例：司马迁对秦始皇的描述是否存在汉代政治偏见？

> 可复用样本。方法论主干见 `../references/attribution-pollution-gradient.md`；完整辩论见 `../../debates/process/truth-discovery-debate-2026-11-17-qinshihuang-han-bias/`，裁判报告见 `../../debates/conclusions/sima-qian-qinshihuang-han-bias.md`。
> **谱系边界**：本书前两案分别处理《史记》全书分层（体裁×时代可靠度梯度）与《汉书》作者归属（家学续作/协作生态）；本案处理**既定作者笔下的单一人物偏见归因**，分析对象与谓词不同，勿与前两案混层。

## 一、主题与命题拆分

- **传统宣称**：《史记》如实直书；或反过来——司马迁纯粹是汉代政治宣传工具。
- **求真命题**：不作整体"有偏见/无偏见"二分，逐层判断汉代政治偏见的强弱。

| 层 | 判断 | 证据等级 | 置信度 |
|---|---|---|---|
| 事件骨架（统一、郡县、巡游、刻石存在、沙丘之崩、秦亡） | 高度可信 | S/A | 高 |
| "暴君"事实内核（严刑、徭役、速亡） | 高度可能（真实） | A/B | 中高 |
| "暴君"道德框架与定性措辞 | 汉初"过秦"话语的结构性投影 | B + 叙事结构分析 | 中高 |
| 沙丘立储（奉诏 vs 矫诏） | 竞争叙事层 | 异文双解 | 中 |
| "焚书坑儒"具体数量与对象 | 过度宣称 + 永久待证 | C/D | 中 |
| "暴君秦始皇"常识形象 | 后世品牌化 / 文学加工 | — | 高 |

## 二、关键证据

- **正面锚定**：刻石颂辞被《史记》录入；司马迁"秦取天下多暴，然世异变，成功大"（《六国年表序》）等承认；陈涉入世家、记刘邦劣迹等多声部反向证据。
- **结构投影证据**：《秦始皇本纪》赞语引贾谊《过秦论》为终篇定评（框架借用）；汉初"过秦"话语配合天命转移的合法性建构（动机—能力—机会—方法链完整）。
- **异文**：《赵正书》奉诏 vs《史记》矫诏——年代相当、各带立场，降为竞争叙事层。
- **D 值**：从秦亡（前207）到《史记》成书（约前91）约116年，到今天约2200年，D≈0.05，落在可信区间但需分层。
- **异常聚类**："坑儒生 vs 方士""焚书令例外条款"等数量/对象异常，指向后世层累而非单点造假。

## 三、辩论转折点：推理者的地基级修正

推理者最初以"事实层/评论层"二分辩护；质疑者指出"每句属实而整体误导"的结构性偏见后，推理者**推翻二分、重建三维框架**（事件骨架 / 道德定性 / 政治语境 + 后世品牌），承认叙事结构层与沙丘立储子层受政治立场塑造。这是**地基级判断更新**，不是"承认小错、坚持大结论"——构成本轮核心求真成果。

## 四、方法论提取

1. **归因污染梯度**（四层模型 + 两条对称约束）。
2. **结构性偏见判据**：同等可信替代编排 + 系统性负面选择。
3. **让步式孤例效力边界**：只作用于个人层，不穿透结构投影层。
4. **框架借用识别**：赞语引后代政论 = 框架借用。
5. **异文双解**：出土 vs 传世异文 → 竞争叙事层 + 永久不可知边界。
