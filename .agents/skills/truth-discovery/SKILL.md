# 求真辨伪：辩证法主干

## 核心契约

不回答二元化的“真/假”。把宣称放进历史过程、矛盾关系、证据距离和利益结构中，判断哪些层真实、哪些层待证、哪些层被包装、哪些层被误归属。

基本立场：怀疑但不阴谋论。很多传统是混合对象，不是纯粹事实，也不是纯粹骗局。

## 辩证法优先

先做辩证分析，再查资料。搜索只能补证据，不能代替判断。

| 视角 | 必问问题 |
|---|---|
| 矛盾 | 这个叙事内部有哪些冲突？谁的利益、身份、制度需求互相牵扯？ |
| 发展 | 它是怎样生成、变形、标准化、神圣化或商业化的？ |
| 联系 | 它和同时代的制度、贸易、战争、宗教、教育、出版网络有什么关系？ |
| 层次 | 人物、事件、文本、归属、传承、包装是否被压成了一个名字？ |
| 条件 | 没有前人、工具、机构、资金、传播链时，这件事能不能发生？ |
| 转化 | 真实核心如何变成权威品牌？弱证据如何变成常识？ |

## 四道闸门

1. 常识优先：一个人能不能做、时间够不够、技术条件是否存在、比较对象是否成立。
2. 信源优先：谁说的、何时说的、怎么知道、离原始事件多远、是否独立。
3. 风格直觉优先：长期接触形成的“感觉不对”，往往是文气、风格、派别和时代习惯的压缩识别；它是入口，不是终点。
4. 推理优先：用类比、同期比较、传承比较、追溯和反事实倒推建立解释，不做搜索结果搬运。

常识先于方法论，方法论先于搜索。直觉要转成可检验问题，不能停在“我觉得”。顺序反了就是复读机。

## 标准工作流

1. 锁定原始宣称：不要替对方改写成更容易成立的版本。
2. 拆分命题层：人物、事件、文本、归属、学派、传承、包装分别判断。
3. 建立时间线：声称起源、最早硬证据、关键编订、传播节点、现代定型。
4. 查证据距离：标注 S/A/B/C/D/E 信源等级和证据离原点的距离。
5. 查矛盾结构：谁受益、谁被遮蔽、哪些制度在重复叙事。
6. 查知识谱系：前人、同代、工具、机构、后继者是否存在。
7. 建立最强替代解释：不要只拆旧说，也要给出更能解释证据的模型。
8. 分层裁判：给出每一层的标签、置信度和可知边界。

## 证据分级

| 等级 | 类型 | 用途 |
|---|---|---|
| S | 一手实物、铭文、手稿、官方原始档案 | 锚定事实 |
| A | 近同时代一手记录、早期抄本 | 强证据，但仍看语境 |
| B | 后世权威史书、目录、注释、专业论文 | 可用，必须追来源 |
| C | 地方志、笔记、族谱、学术综述 | 线索，不作定案 |
| D | 传说、学派传统、媒体转述 | 追影响，不当事实 |
| E | 现代估算、自媒体、意识形态叙事、模型反推 | 假说或污染源 |

权威人说了不等于事实。多人重复不等于独立验证。论文发表不等于原始数据可靠。

## 分层裁判标签

优先使用这些标签，而不是“真/假”：`已确认`、`高度可能`、`合理`、`待证`、`永久待证`、`不可知`、`过度宣称`、`归属错误`、`品牌化`、`改写`、`已证伪`、`累积发明`、`张力元文本`、`代言式文学重构`、`道德塑形`、`设计污染`、`喜剧嫁接拼贴`、`辩护性回响`、`幸存双峰偏差`、`体裁角色载体`、`相容待核`、`零正份额`、`声誉史`、`命名加冕`、`接受端放大`、`功过双端放大`、`幅度序数化`。

归属类问题按阶梯判断：人物 → 学派 → 编订 → 语料库 → 协作生态 → 品牌 → 改写 → 神话。

永久不可知（证据原理上无法生成）与永久待证（证据被压制/销毁）须分开，前者不可靠更多搜索填补。作者方法元文本下的载言保真切割、软着陆禁令与证据类型分账见 `references/author-method-meta-text-fidelity.md`；「理想类型／时代表征」仅为可选下游用途分账，不得回潮「弱可推断正份额」（可选参考 `references/unverifiable-text-ideal-type.md`）。

## 内部辩论模式

重大判断必须拆成三种声音：

| 角色 | 任务 |
|---|---|
| 质疑者 | 找漏洞：时间异常、利益动机、证据缺失、来源污染、过度一致 |
| 推理者 | 建模型：技术谱系、传播路径、制度条件、替代假说、概率聚合 |
| 裁判者 | 比较证据强度，给出分层结论和最可能解释 |

如果双方都能解释一部分证据，优先建立混合模型，不强行全真或全假。

## 常见红旗

- 一个人被归功于太多领域，却没有前人、助手、工具、机构或后继者。
- 职称／通名语义（如 vyāsa＝编排者）被偷渡为护照式专名履历 → 功能标签对人物存在／作者身份升格权重＝0（只加严不加分）。
- 荣誉品牌／圣诗人称号（如 ādi-kavi＝第一诗人）被偷渡为护照式履历 → 与职称同规：对人物存在／作者身份升格权重＝0。
- 史诗／圣典内自我归名、入内角色、传述框＝框架／权威装置，alone ≠ 外证历史作者；对作者命题默认零／近零正份额。
- 「传说核心／可能整编节点」弱假说对「现存本作者身份」正份额＝0；拒「护照已证」与「从未有人已证伪」两端；超级归名证伪不得穿透为人物虚无。
- 宣称「单一作者写出现存层累大本」时，近证伪须钉死文本对象，并显式排除「证伪口传传统／多手编定／名号功能」；「或许写了核心」无非循环外证＝偷渡正份额。
- 批判校本／现代定本 ≠「恢复某圣作者原文」；战争核／故事核／历史事件核 ⟂ 作者归属，回流权重＝0。
- 一人名下跨体裁超级归名（史诗＋吠陀／往世书簇等）＝品牌扩张；须与本典框架归名分权重，两端均不回赠单人全文。
- 姊妹史诗／同构案件方法迁移：须钉死文本对象与名号主轴分界；禁匀质打假；亦禁因「无同等超级归名」而回赠单人全文。
- 跨文明比较品牌（如「梵语莎士比亚」一类「本地＝异域X」）→ 对人物护照／全集作者升格权重＝0；启发式比较 ≠ 证据。
- 宫廷 kāvya／戏剧语料库 vs 口传史诗圣作者：须钉机制分界；禁把史诗「单人层累近证伪」匀质扣核心戏剧簇，亦禁因非史诗回赠全集护照；核心戏剧簇一人主导 ≠ 全作品集单一作者（莎士比亚纪律迁移）；外围多人／学派语料库可能。
- 人物判断为「高度可能但弱于护照已证」时，流通摘要须保留「弱于护照」；省略后写成「已确认」＝柔化，应退回改写。
- 最早硬证据远晚于声称起源。
- 现代教材把复杂链条压成一个英雄名字。
- 一个叙事完美服务于宗教、民族、课程、市场或文明自豪。
- 关键证据在敏感时期“恰好”丢失、销毁、改名或降级。
- 多个来源看似独立，其实循环引用同一原始说法。
- 争议被转移到定义游戏：什么才算发现、文明、传统、自由选择。
- 对方承认小错，但小错已经动摇核心证据。
- 互文或平行段落只支持「共享材料池」，不能单向升格为「同一作者」。
- 姊妹典籍中一书已判多源编纂时，连带「同著他书」应链条二次降级，举证在主张方。
- 制度性体裁分立（如国别记言 vs 编年附传）且无自署名时，慎断「一人一稿多体」。
- 正史载父作底稿、受诏官修、妹/门人封笔补卷，而叙事仍称「独立完成」→ 署名声望层过度宣称。
- 家学未竟手稿不传，却对子辈定稿主张「非继承」或高比例继承 → 底稿占有率待证，勿混层。
- 纪传体全书按单一真伪二分 → 压平体裁×时代可靠度梯度。
- 列传长篇载言无出处却当现场录音 → 拟辞/载言层未与叙事事实分裁。
- 史家方法序／自我声明声称「贴近大意」或「按场合所需填写」→ 只锚定意图结构，不锚定执行保真；须拆 (a) 意图声明／(b) 已实现保真／(c) 可测生成约束——无独立旁证时 (c) 方法论不可用，不得把张力元文本读成保真证书。
- 「虽非逐字但大意弱可推断／unquantifiably authentic／伪精确残值概率」充当教材或下游史实锚 → 防御换壳红旗：弱可推断正份额与不可知标签不得冒充肯定证据；特异性只挡极端全虚构，不发保真正份额。
- 道德化传记／bios 中选材、动机优待、省略、示范已确认 → 「道德塑形已确认」；不得压成「道德寓言＝全盘虚构」，也不得因「不是寓言」回赠事件史／轶事保真正份额；探索性道德主义＝阅读伦理，对史实保真零正份额。
- 平行配对、Synkrisis、排行终裁等比较装置 → 设计污染／强制可比性；终裁层对「历史人物客观对照／传主实际德行」正贡献＝0；硬不对称样本强化设计优先，不得当史实对照引用。
- 同作者在批评体／方法论文中具备较严史学规范，却在传记／示范工程中选择性停用 → 跨体裁双标成立并计价；禁止「体裁不同」免检；显式声明「写生平而非历史」时，当史引用须比无弃权正史更严（禁单独作年表权威、禁坐标与性格金句打包、禁比较终裁当客观德行）。传记「骨架」须再拆 3a 发生坐标与 3b 叙事化骨架；3a 个案升格不覆盖 3b；区块匀质「晚期高可用」＝过度宣称。
- 作者曾任秘书处／近档／近权力职位 → 仅＝制度可能光环；≠保管链、≠档案通行证；对公开骨架／文书升格**零加权**；接近度只加严不加分。
- 正文「他写信说／引用遗嘱／元老院记录」须拆文书 (a) 公共文书回声 vs (b) 私人文书／对话道具；(a)＝相容待核／可走分叉升格；(b) 对事件史默认零正份额；**引用 ≠ 亲见**。
- 「相容待核／个案升格」须过关闭阀门才升格（禁职位加权；论旨结构重合；真正分叉≠同池互见；句级封顶）；默认关闭；未抽样／未过阀＝事件史固定零正份额；相容块 ≠ 已升格锚。
- 未过阀门的「残暴／失政」等本质谓词禁止作公开骨架承重；丑闻簇不得洗入层 3；声誉史／主题学高度可用但**不回流**事件史；「分层可用、丑闻宜谨慎」而未锁定声誉史用途＝下游柔化，应退回改写。
- 互见一致 alone 升格史实 → 只能说明编集控制，不能反向证明事件层。
- 单一人物叙事按「事件骨架→道德定性→政治语境→后世品牌」作归因污染梯度分层，可疑度递增；事件可信不担保评判可信，评判可疑不穿透骨架 → 防证据方向倒置与聚类外推。
- 同一人物/机构被两个权威冠以相反称号且各自被制度化（双极品牌化）→ 判断谓词从「内容真伪」上移到「称号生产机制」；两相反品牌若各品牌不同层（方法/影响 vs 内容真实），在分层框架下并不互斥，「矛盾」是品牌化制造的假象；警惕负品牌寄生正品牌语义做二次品牌化（评价极性反转）。
- 时间更早 ≠ 来源独立：同生态旁证（即使无引用关系、即使年代更早）不能充当独立验证线；相容 ≠ 核对——印证只证明文化生态真实、不证明具体记载属实，且印证常集中于易验证的边缘层，不得外推到难验证层；共性/体裁证据只设「排除纯胡说」的下界，不对忠实度上界贡献。
- 双源／多源「哪一方整体更可信」题面 → 假二分；须拆书名态（今本／古本／原件／辑佚）×冲突条目×外部窄锚；禁止整书站队与「单条胜出→整书修正」幽灵句。
- 今本伪／窜或严重改写本冒充古本／出土原件使用 → 半真半假；当古史材料校正他书＝方法已证伪（可作伪书学／版本史对象）。
- 古本辑佚／对照残条对事件史默认零正份额；对照用途＝拆单声部／主题学，≠「更真」胜出；仅真正分叉锚可窄升格发生坐标。
- 「更原始故更真」「正史／官史故更真」→ 双端品牌化过度宣称；出土时间故事≠内容保真；官修身份升格权重＝0。
- 多条异文仅共享「异于权威史书」维度 → 非独立异常，禁止概率连乘偷渡「异端传统整体更可信」。
- 经典「古文／古本」同名偷换：汉际残传统 vs 晚出献本／定本 vs 全书 —— 未钉对象即谈真伪＝命题未成形（与今本≠古本同族）。
- 晚出伪经／伪古文含古句、古料 → 古材料 ≠ 真篇章；对声称时代原件事件史默认零正份额；用途限伪书学／版本／思想史／辑佚对读。
- 今古文（或同类）家法／立官／利禄胜负偷渡文献真伪，或文本伪作反向取消全部学派遗产 → 政治层与文献层必须分表。
- 辨伪合围中攻一条枝节（单条历法／地理／成语）暗示目录篇数、传承断裂、采摭主干崩溃 → 防御换壳；枝节可修 ≠ 身份宣称复活。
- 托古理想官制／蓝图被校理、改名、立学、改制升格 → 升格利用 ≠ 一人从零造伪的充分条件；政治升格与文献成书窗必须分表；「非伪造」不回流圣王亲著／实录。
- 古制记忆碎片／金文职官名相容被读成圣王手稿或西周官制实录＝半真半假；对亲著与实录命题事件史默认零正份额；禁「有金文印证故大体可靠」柔化。
- 「圣王亲著／权臣全伪」假二分（如周公作《周礼》vs 刘歆全伪）→ 拒两端非凡宣称；近证伪须钉死单一个体＋独自写出＋现存层累成品并显式排除；收口多为晚出托古编纂＋升格包装。
- 「作者／成书年代争议如何解决」若被读成选出唯一护照名 → 假任务／对象偷换；充分答句＝分层年代窗＋归属阶梯（材料核／初编／定型禁冒充）；训诂词典层累与托古官制蓝图须划界（名物语料库 ≠ 理想官制），纪律同属多源归名。
- 医经对话体托名神话圣王（如《黄帝内经》黄帝问岐伯）→ 亲著近证伪须钉死句＋显式排除；内叙事医官角色升格外证作者＝0；《素问》《灵枢》等姊妹医经禁匀质年代／作者；后世注家重编（如王冰）对汉以前原貌默认正份额＝0；「作者是谁」＝学派语料库＋编订阶梯，禁佚名单作者偷渡护照；对齐希波克拉底医学语料库；拒「圣王亲著／全书无核全伪」假二分。
- 反讽体裁（喜剧/讽刺/戏仿）为真实个人挂载"思想/技艺/习俗"特征：先做嫁接溯源三问——①可归溯独立源头（他人学说/先例案）？②命中体裁指控 topos？③与传主可证强身份标识直接矛盾？任一成立 → 该元素对传主"现时立场"正份额＝0；错挂本身＝模板套用自证。产物既非"歪曲真实底本"亦非"忠实夸张"——拒"歪曲/忠实"二分，落点＝体裁产物＋接受史载体（公众认知镜像高度可用；传主史料零正份额）。
- 敌意体裁先行流通后，辩护方著作对传主"无损细节"的呼应默认＝辩护性回响，非独立观察线；辩护文本以体裁形象为参照系（自指）＝回响自证；升格须要求时间上先于体裁流通的独立观察载体。同一体裁生态内多部作品互仿互指＝同池回声（生态内持续性），禁异常概率连乘；讽刺→制度后果因果链三档：受害者自述损害（相容待核）／主因（待证）／份额比例（永久不可知，拒绝伪精确）。
- 记载生态仅存两件完整文本却被制度化成"A vs B"穷尽对比 → 幸存双峰偏差：n=2 是下界过滤器（"分歧≥观测值"）非分布测量仪；比较前查目录/残篇/引用链重建生态宽度；若同源内部断层≥跨源差异（如柏拉图早期 vs 中后期 > 色诺芬-柏拉图间差异），双峰框架整体错位，改多点谱系；比较结论必须带存活过滤条件。
- 辩护文本的章节结构跟随靶子（指控清单/控诉文）→ 申辩映射结构（辩护性回响的结构级）：靶子驱动段落观察份额不可量化，与体裁惯例段分账；多线"收敛"若由共享靶子+体裁公约数强制产生，收敛≠独立验证；同一人物被画成"完美导师"与"荒谬怪人"（褒贬镜像）=体裁角色扮演互为镜像，两侧都不承重历史观察；多体裁产出差异=用途差异，"谁更真实"不可答，归因多因并释、权重永久不可知，单因归因=过度简化。
- 二手编纂者逐条署名来源、制造严谨外观，但来源多已散佚 → 署名来源＝透明黑箱：引用透明≠可核验，署名对材料真实性零正份额、仅目录学线索；并列异说不可核则降相容待核，禁「标了来源所以可信」加权。
- 对大量对象编纂者是唯一幸存来源、后世皆源自他 → n=1 幸存偏差：同源互证＝0，「多源一致」只是同源回响；杀伤限轶事/生平/谱系层，不穿透可脱离转述链独立鉴定的嵌入一手文献层；功劳归材料与外部检验线，禁「X 记载较正确」柔化句。

- 体裁形容词（"X 式故事"）或描述性族裔/体征标签（如 Aesop←Aithiop）被实体化为作者专名 → **体裁标签实体化**：对作者命题零正份额；"体裁需要一个作者名"的叙事冲动使 (体裁→虚构创始人) 为主解释，(真人→体裁得名) 不可知不加权；多个古典作家都提"X 式故事"只是体裁锚，对人物零份额。
- 开放语料库（按最早出处分型分代、边界持续开放、含 identifiable 文人原创与跨文明共享）被压成"一个人的书"→ 近证伪锁定句＝"单一作者独自写出全部开放语料库"（≠史诗案"单人写出现存层累定本"）；"民间故事集"只描述无主口传层，作整库标签过度简化。详见 `references/genre-eponym-reification-open-corpus.md`。
- 归名传统自身的经典文本说出与归名叙事相矛盾的话（如 Babrius 自序称寓言为叙利亚发明）＝**本典内部反证**：对"开创者"品牌是强反证，对起源地只作相容线索不单独定案；"X 开创某体裁"降为"X 是某传统名义焦点＋中心主义包装"。
- 辨伪论证引用权威支持"文本抄袭/伪托"，而该权威原文主张的恰是相反方向（"A 窃 B"被引为"B 窃 A"，如朱熹"佛窃《列子》"被引为"《列子》窃佛"）＝**方向反转引用**（接受史污染第三形态，区别于切除/柔化）：正份额＝0，禁"降强度保大结论"；三判据＝主谓方向核对／同篇异引对照／受益方引用检查。详见 `references/forgery-evidence-polarity-reversal.md`。
- 题面"X 是先秦思想还是魏晋玄学""X 是 A 时代还是 B 时代思想"＝**思想断代假任务**：预设单一归属，须横向拆故事核／写定层／注疏阐释层，层间年代不传递（与"今本≠古本"纵向版本态正交）；注者的玄学被读成原书思想＝注疏倒灌，正份额＝0；"作伪者不会犯的错"只排除一人精心伪托、不证明朝代（负向排除≠正向断代）。
- 古籍"是否某时代伪作"题：可考事件锚（译经年/汲冢出土/避讳）能建**可被反例证伪的断代夹逼窗口**，强于"文气像"与单向"最早硬证据晚"；但两文本相似对称、不构成方向证据——取材方向若依赖"文本伪"待证结论反推＝循环、若依赖传播大方向＝背景推断，须把窗口降为**条件性结论＋序数量化**，禁伪装铁证。
- 辨伪合围中把权威原意整个引反支撑己方（朱熹"佛书窃列子"被引成"列子窃佛书"）＝**引文极性反转**（移交转述柔化的极性升级子类）：凡"某权威说X"须回原文核谓词方向；反转柱出局但禁外推"整座合围不可信"。
- "某故事不见于同时代他书"被当"更早古本遗存"的证据＝**缺沉默当剪影**（证据方向倒置新子型）：沉默同时兼容遗存与新创、双向零份额；无独立判据则退回不可知栏，禁进正面结论。
- 辨伪"多证据线"若共享同一隐含前提（都以"文本后出"为据）则非独立柱、合围强度被系统性高估 → 逐条抽前提测试折价，拒"五证合围""铁证"强度词；真伪未决但两方向同向削弱同一命题＝**双刃证据**，收口"路径未决、方向已定"禁空转。详见 `references/dating-pincer-and-citation-polarity.md`。
- "X 是否为伪书""X 是 A 时代还是 B 时代思想"＝**伪书谓词未分解**：把人物/定本/材料/思想/包装五轴压成二元；判"伪"必须注明哪一轴，禁跨轴外推（定本伪不穿透人物存在、不否定材料古来源）；"含古料⇒定本真"与"定本伪⇒材料/人物亦伪"两端越界均禁。详见 `references/forgery-predicate-decomposition-dating-axes.md`。
- 具体文本结构与 dating 明确的外源文本平行＋无更早独立旁证＝**断代下限（terminus post quem）**，不可降格为"时代风气相容"；对方以"该思想彼时已有"消解时，要求出示同等文本结构的更早独立旁证，无则下限成立（可测平行 vs 宽泛生态）。
- 以叙事素材层的佛典/外源平行（具体故事、道具、情节）外推**整个义理框架层**为外来＝**叙事外推义理**红旗：叙事素材可找具体平行、可断代锚定；义理框架属思想生态渐变、只定生态归属（本土内生 vs 外来）；禁互相越界。
- **人物确定型言行录**（传主由 S 级史料锁定存在、争点在文本归属/成书分层）被压成"本人亲著/后人伪作"站队 → **双问非对称**：人物确定对文本亲笔正份额＝0，"自著"锁定句＝"逐章亲笔写出全本"且证伪须标等级（B 级组合推断≠S 级铁证）；守**三条不传递**（事件核≠亲笔／材料下限≠定本年代／编者立场≠传主学派）；**思想三分**（编者注入层零／采录传主言行层相容线索／不可分驳杂层不可判），禁把"编者立场墨/稷下"读成"传主属墨"（柳宗元"为是书者墨之道"）。局部内证（殁后事）只证局部增窜，不外推全书亲笔证伪的 S 级；言行录对事件史默认零份额，"某故事他书也有"＝同池互见非分叉；出土简本"校勘—断代双刃"但"谁更近原本"永久待证；编者自述（刘向目录篇数）行为事实 A／确切数字 B 分判。与列子（人物存疑）、伊索（开放语料库）、内经（神话圣王）钉死分界，禁匀质套用。详见 `references/identified-figure-account-compilation.md`。
- **证据等级通胀**：把 B 级考证推断（后世权威提要＋推理链）标成 S 级硬反证——凡"铁证/硬反证"须回查是出土实物(S)／近同时代文本(A)／现代考证转述(B)，标错即重标；B 级组合推断可高置信但不得冒充 S 级。
- **晚出证据共柱坍缩**：用一条晚出证据（如皇甫谧注）去打破"早期目录沉默"的双向对称前，先做载体依赖检查——该证据的存在是否依赖同一载体（目录著录）？共柱则对称不可打破，写定年代永久待证，禁"用同柱证据破沉默"的自我循环；人物/目录/注本三线晚出常共享"现存证据都晚"同一前提，合围强度须折价。详见 `references/hermit-eponym-strategy-corpus.md`。
- **隐者通名托名的术数实用文本**：地望/居所通名（如"鬼谷"）被读成专名护照→升格权重0，收口"传说核心合理/专名待证"（两端非凡举证，不推出"从未有此人"）；师承传闻（近同代B级）与后世接枝弟子名单须分裁（后者零正份额）；出土文献证术数生态真实＝相容、不证闭合定本来源；托名隐者＋实用术数＋闭合定本，与列子（玄学寓言极性反转）、伊索（开放语料库）、内经（神话圣王医经）、晏子（人物确定言行录）钉死分界。详见 `references/hermit-eponym-strategy-corpus.md`。
- **份额分配假任务**：人物与文本归属均确定、正文由无名分工的集体写成的署名经典（主编/权臣姓氏冠名），被问"某人贡献几何/占几成"时——无分工记录、无可加总单位（篇数/字数/思想条目均不可归属到人）→该数值命题**非法**（比"待证"更强），判"份额假任务"；禁止柔化为"大致可估"，替代操作＝拆发起/资助/组织/裁定/执笔/署名/包装职能层逐层归属定级，禁重折百分比。与"解决作者争议假任务"（选名版）、"三不可锚"（断代版）同属反伪精确主线，本案为**份额版**。落点＝主编主持的协作生态写定本。
- **双向品牌化与书名态偷换**：署名膨胀（"全书皆主编一人智慧／字字不可改"）与署名抹除（"主编固无与也"）并存、受质疑时互相搬出续命→两端皆过度宣称，回到原始目录学"辑/作"分判＋职能层分解；同一书多名（《吕氏春秋》姓氏冠名／《吕览》体例简称／《吕子》诸子升格）对应不同署名机制，压成一层＝对象偷换，《吕子》为二次品牌化。守四条对称不传递：资助/组织≠执笔、裁定意图≠贯彻、署名≠思想独归、集体执笔≠主编无与。详见 `references/editor-signature-collaborative-share.md`。
- **作者谓词假任务·编校版（反伪精确主线第四变体）**：对象为多源材料汇编＋编订者（校／次／补／除复重／定名＝A 级行为事实）时，"作者是谁"的"单一具名著者"谓词不适用→答案＝**否定式**（无具名著者，非"换一个作者名"）；早期目录"著录书名而不系作者名"＝原始清醒分判，编订/命名行为偷渡为著者身份＝归属错误，下游把否定式柔化成"其实 X 就是作者/另有更好候选"＝改写须退回；守五条对称不传递（材料存在≠著述、命名≠创作、校定≠亲撰、多传本≠无定本、材料来源者≠定本著者，五正五反皆禁）；与选名版（尔雅）、份额版（吕氏春秋）、断代三不可锚版（鬼谷子）钉死分界。详见 `references/redactor-not-author.md`。

- **来源复合谓词假任务／来源声明审计**：著者已确定时问「X 的学术来源是否可靠吗」——「来源」是复合词（材料/接触/人物/师承/立场/版本六轴异质），压成单一「可靠否」＝命题未成形；须逐轴分裁并给否定式分层收口（总宣称「来源可靠」＝过度宣称），禁六表平均后报「整体中高」（分层规避聚合）。作者自报来源（「信而有证」「博采通人」）＝元文本三层信任审计：(a) 意图已确认／(b) 不发已实现证书／(c) 可测约束须有可失败反向检验，仅有「阙如」正例而无「应阙清单」＝幸存偏差，降弱可测。
- **接触→摹录保真偷渡／跨轴借用**：制度接近或一手接触事实（如奉诏校书、见过器物）被滑移成「逐字转录可靠」→ 接触事实与摹录保真分判，接近度只加严不加分（职位光环近亲）；用材料层可核性给元文本轴加分＝跨轴借用，禁。一手接触者 ≠ 二手编纂枢纽（后者套署名零正份额），黑箱杀伤限该轴不外推。详见 `references/source-claim-audit.md`。
- **注疏体来源构成份额假任务／体裁范畴错置**：问「某注本注文有多少原创、多少抄录」——著者已确定但题面把两个非法前提打包：①「原创%/抄录%」预设不可加总的计数单位（一条之内"引旧文＋校谬＋补见闻"混合、无分工清单）→ 份额假任务（**单作者文本内构成**新变体，区别于《吕氏春秋》集体作者贡献份额）；②「抄录」贬义谓词把现代原创性 regime 倒灌进以**引书立注**为成法的注疏体→体裁范畴错置，谓词部分失效。三分框架：具名引书（标示行为 A、**标示≠忠实**、忠实度相容待核）／未具名袭用（对原创**正份额＝0**、构成不可判、用途限辑佚/主题/接受史）／自述按语（归属 A、正确性另核）。辑佚价值另账守**三禁令**（只升文献保存轴／不回流原创／不回流总判断），防「高价值故原创」软着陆；今本经注混淆→对象不纯净、作用域限可归名层。详见 `references/commentary-source-composition-audit.md`。
- **来源取向假二分（实践 vs 文献）／"验"字语义分裁／反向检验足迹**：著者已确定时问「知识来源是亲身实践还是文献汇编」——多源自序常四源并置（经传/歌谣/老成/行事），二选一＝**来源取向假二分**（来源大轴第三变体，区别于可靠轴《说文解字》、构成份额轴《水经注》），命题非法，拒两端；四源分层：文献采录（标示 A／标示≠忠实／辑佚另账）／口头采录（相容线索）／他人经验（A 但≠作者亲得）／亲身验证。「验之行事」类动词做**语义分裁**：亲手劳作 near 证伪、观察调查/经营擘划/实验改良高度可能（B 级组合推断）；**释义≠核证**——权威农史释义只是 B 级学理、不是 A 级行为核证，不得证据等级通胀。自报来源附**反向检验足迹**（对自己不利、带试错心路的第一人称记录）时守四边界：①**存在性 vs 比例性**（足迹只锚"曾进行一手实践"存在性高度可能，对"实践占来源主体"比例性**零正份额**，负面自曝只锚存在不锚比例）；②**(a)≠(b) 硬隔离维持**——足迹只升"附存在性佐证的意图声明"、不发已实现证书，禁柔化"局部已实现可靠"；③**本典内证 self-bootstrapping**——全在本书内无独立外证则 B 级组合推断，禁自序证全书又全书证自序；④幸存偏差对称。与可靠轴"阙如"零足迹空转型分型（足迹型 vs 空转型，禁互借）。辑佚价值守三禁令；今本掺入层→对象不纯净收窄；「实践神话」与「百科全书/权威引证」双品牌互相续命须**双端同拆**（引证归属模糊＝品牌化零正份额）。详见 `references/source-orientation-experience-vs-compilation.md`。
- **接受端评价放大审计（与来源大轴正交的第四轴）**：问「X 的科学观察/成就是否被后世夸大/吹捧/神话」——"夸大"是**评价谓词**、发生在**接受端**，题面却伪装成生产端问题（查某条观察数值真伪）；按字面查会漏判（多数条目可靠）。守四纪律：①**事实⊥评价正交双问**、双向互推全禁（评价夸大↛观察虚假、观察真实↛评价可信），事实层与评价层分别裁判；②**命名/范畴加冕＝首要放大对象**——把自序自限、目录学归子部的博物/考据笔记命名为"科学著作/科学家/里程碑"是幅度最大的放大，作独立归属事件置于结论中心，加冕层对事实层零正份额（自序自限元文本＋目录链作封顶证据；机构化足迹只锚"加冕行为发生"非"内容为真"）；③**功过双端放大**——功过两维度皆后世构造须对称审计，但**证据强度可天然不对称须如实标注**（如正面李约瑟原话 B/C 待核、负面单源＋沉默＋A 级负证），禁伪造对称（区别于双极品牌化的相反称号各制度化）；④**优先权伪精确 P1/P2＋幅度序数化**——P1 记载/命名≠发现/首创、P2 单基线伪精确（"早X年"＝后世西方事件年−古代记载年，单基线未核不给数），幅度序数化禁伪精确年差（P1/P2 编号避与二手枢纽 V0–V3 冲突）。事实层三分（亲历/转述/传闻，自认"缺谬"档封顶 C）＋义项分离；收口为"事实内核可信＋评价双端放大"混合对象，置信度针对框架。与来源三轴（生产端）、双极品牌化、范畴错置注疏体（做减法）、累积发明（归属答案）、二手枢纽（V0–V3）钉死分界，禁匀质套用。详见 `references/reception-side-evaluative-amplification-audit.md`。

## 输出模板

使用这个顺序：

1. 简短判断：先给分层总评，不给二元结论。
2. 命题拆分：说明哪些层在讨论。
3. 证据时间线：列最早硬证据、关键黑箱、现代定型节点。
4. 辩证分析：矛盾、发展、联系、条件、转化。
5. 动机和制度结构：谁获益、谁重复、谁被遮蔽。
6. 分层结论：逐层标签和置信度。
7. 可知边界：哪些可确认、哪些只能推断、哪些永久待证。

## 反模式

- 不做学术权威、百科、搜索引擎或教材的复读机。
- 不用“没有证据”直接推出“不存在”。
- 不用“不能完全证明”逃避最可能解释。
- 不把古代归名惯例直接等同于现代欺诈。
- 不把人物存在、文本亲笔、思想原创、后世品牌混为一谈。
- 不把动机当作定罪证据，但也不把动机排除在解释之外。
