# 案例：维特鲁威《建筑十书》是否确为一人所作？（第 60 场，23/25 入库）

## 问题

维特鲁威《建筑十书》"是否确为一人所作"——确定署名的技术专著被问独著与否。

## 关键事实分级

| 事实 | 等级 | 锚什么 |
|---|---|---|
| 献辞+贯穿第一人称、抄本一致 | A | 文本自我呈现为某人作品（不发作者真实性证书） |
| Pliny《自然史》一处提及 | A/B | 有此罗马工程师（独立旁证） |
| Faventinus "Vitruvius Polio aliique auctores" | B | 名号流传；短语歧义不锚全名/人数 |
| OCD：compiled partly from Hermogenes 等、sometimes disjointed | B（权威工具书） | 编译性编纂、素材多元、内部脱节 |
| 中世纪抄本北欧来源、1414"再发现"、1486 印本、1511 补图 | A/B | 现存本非原貌（后世编辑层可分离） |
| 维罗纳/Thilbilis 铭文同姓 | C | 家族线索，零正份额于作者身份 |
| 生平（军旅/法诺会堂/相貌/求委托） | 本典自述 | 自述循环，仅 (a) 意图层 |
| 中文伪史论"伪书"（凯撒虚构/印刷术） | E | 理据自相矛盾，零正份额 |

## 辩论关键转折（M1–M4 四项修正，教科书级三项）

- **M1（教科书级）抽掉测试→判据簇**：初判"作者性纯度审计"为新轴，经抽掉测试发现人数/纯度两问被伪书谓词人物轴/定本轴吸收，主动降为编订/改写层判据簇、不新设桶。通用纪律：新轴设立前必做吸收性自检。
- **M2 对象不纯净·作用域收窄**：锁定句钉死到"可归名原初写定层"，后世编辑层（抄本/再发现/补图/印本）可分离、零正份额回填，显式排除"包括插图/印本"。
- **M3（教科书级）弱否定非正面证据**："无多手硬证"是弱否定，不是"一人统筹"的正面证据，据此把"一人统筹"由高度可能降为合理偏弱。与"缺沉默当剪影"反向同构（彼否定对方，此肯定己方）。
- **M4 最强解释非核对**：内容异质性+disjointed 给"一人广读编纂更省备"的方向性弱推理，明标最强解释、不升级置信度。

## 核心结论

"确为一人所作"是复合谓词，三问各自定性、无统一答案：人数**待证**、执笔**编译性编纂高度可能（纯逐字自撰过度宣称）**、纯度**非原貌已确认（对作者性零正份额）**。落点＝一人统筹的编译性技术著作，人物弱于护照、整体 0.86 针对框架。双向对称不传递：来源多元≠多人执笔、一人执笔≠材料纯自创。

## 核心方法可迁移

1. 抽掉测试（新轴合法性闸门）：能被既有轴吸收者不得新设轴桶。
2. 复合谓词三问正交（人数⊥执笔⊥纯度）：凡"是否一人/独著/原创"类题先拆轴。
3. 弱否定不充能：对方主张无证据≠我方正面证据，禁止借电。
4. compiled 署名=统筹≠逐字自撰：署名层范畴错置禁令。
5. 自述循环+旁证射程：生平自述禁发证书，独立旁证只锚名号流传不锚人数。

## 与既有范式分界

vs 反伪精确四变体（不争选名/份额/断代/编校者身份）；vs 伪书谓词分解（前提是**真书**，争作者性非真伪）；vs 言行录晏子（争 compiled 署名非逐章亲笔）；vs 来源三轴/内容轴/评价轴/认知操作轴（争作者性纯度，非来源/内容/评价/认知操作）。详见 `references/authorial-purity-audit.md` §九。
