# 案例：苏埃托尼乌斯《十二凯撒传》——帝王轶事—类型学 bios

## 二、方法索引（本案真增量）

1. **职位光环 ≠ 保管链**：接近度只加严不加分；升格权重＝0。  
2. **文书 (a)/(b)**：引用 ≠ 亲见。  
3. **V0–V3**：缺一不可；默认关闭；未抽样固定零；相容 ≠ 锚。  
4. **残暴谓词隔离**：禁丑闻簇洗入公开骨架。  
5. **声誉史可用不回流**；**禁柔化句**（「谨慎可用」≠ 低置信事件史）。  
6. **复用（不重写）**：轶事事件史零正份额；互补双重品牌；同源互证／相容≠核对。

## 三、辩论锋利刀

1. **七层拆分＋职位≠保管链／引用≠亲见**：钉死制度光环与「他写道」分类遮蔽。  
2. **残值通道三联拆除**：弱制度残渣、无阀门升格、谓词洗钱、待证柔化、相容混锚 → M10–M17。  
3. **表 A/B 最小抽样**：只示范阀门，禁读成全局升格比例。
