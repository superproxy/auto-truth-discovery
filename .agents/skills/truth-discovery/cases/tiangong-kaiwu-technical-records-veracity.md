# 案例39：《天工开物》宋应星的技术记载是否均为当时实有技术？——技术内容真实性审计（存在性⊥保真性）

> 结论全文：`debates/conclusions/tiangong-kaiwu-technical-records-veracity.md` ｜ 方法长参考：`references/technical-records-veracity-audit.md` ｜ 结案 2026-11-25（第 57 场，辩论 3 轮，24/25 入库）

## 问题

《天工开物》宋应星的技术记载是否均为当时实有技术？——题面"均为"是全称量化命题，"实有"一词偷换两个正交谓词：**技术历史存在性**（该技术明代是否实有）与**记载可复现保真性**（宋的记载是否准确完整）。真问题：存在性与保真性是否正交、观察者身份如何限制保真、加冕是否误作保真背书。

## 辩论关键转折（推理者四项修正）

- **M1**：保真性层给整体评级"参差不齐"，单列"漏关键工序型错误"（炼锌漏还原剂、曲蘖漏酿酒法），不再用"分层"回避整体判断（响应分层收口律）。
- **M2（教科书级·新增）**：确立保真性第二独立限制维度 **观察 ≠ 理解**——现象观察层可高保真，原理判断层受"文人无自然科学训练"限制；硝石/朴硝混淆＝"看得到现象、分不清原理"，非单纯转述失真。错误三档（漏工序/概念混淆/判断错误）对认知能力的暴露程度递增。
- **M3**："亲历层较高保真"降级为"合理（B 级背景佐证）非已确认、不作承重柱"；承重柱让位给两个可核硬事实（存在性多互证 S/A／保真性有可指认错误 B）。
- **M4**：确认"百科全书"加冕对内容准确性正份额＝0，且点明**广度与精度存在张力**（覆盖越广越易越界依赖转述、越易出错）。

## 核心方法（可迁移）

1. **存在性 ⊥ 保真性 正交双问（新轴）**：技术实有 ↛ 记载准确、记载有误 ↛ 技术不存，双向禁互推。炼锌"技术实有（S）＋记载漏还原剂（B）"同时成立即铁证。
2. **全称命题破产≠滑向多杜撰**：一个反例破"均为"，但反例打的是保真性不是存在性；正确收口是"存在性多数实有＋保真性分层"，禁"保真缺陷→技术不存"方向倒置。
3. **保真性三限制维度**：转述失真（接触≠摹录同族，对象换观察）／观察≠理解（原理判断层受认知限制）／漏关键工序型错误（记载非完整可复现方案）。
4. **亲历层保真降级纪律**：履历佐证 B 级＝合理性非核证；逐篇难定量则"亲历层较高"降待证、不作承重柱；防"承认小错坚持大结论"防御模式。
5. **加冕剥离＋广度精度张力**：范畴广度加冕对内容准确性零正份额，且广度与精度负相关（覆盖越广越易出错）。
6. **混合对象收口**：存在性高＋保真性分层；防"存在性高"柔化成"记载可信"。

## 与同族划界

- 与来源大轴三轴（`shuowen-jiezi-source-reliability` 可靠轴／`shuijing-zhu-source-composition` 份额轴／`qimin-yaoshu-practice-vs-compilation` 取向轴）划界：前三轴问"知识从哪来/怎么构成"（来源），本轴问"记的东西真不真"（内容）——同在生产端，但内容 vs 来源正交。
- 与接受端轴（`reception-side-evaluative-amplification-audit`，梦溪笔谈）划界：那是"后世如何评价"（接受端·评价），本轴是"所记技术本身是否实有/记载是否准确"（生产端·内容）；梦溪笔谈落点是"命名加冕首要放大"，本轴落点是"存在性高＋保真性分层"，两者不互推。
- 与 `commentary-source-composition-audit`（水经注）划界：那是注疏体"原创/抄录"份额（文本构成），本轴是技术专著"所记技术真伪"（内容真实性），共享"文人观察者"认知限制但对象不同（抄录 vs 观察转述）。
- 与 "观察≠理解" 的近亲 "接触≠摹录可靠"（说文解字来源轴）划界：后者是抄录层保真，本轴是理解层保真，同族不同档。
