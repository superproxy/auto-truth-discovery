## 核心判断

拒斥"全书伪/全书真"与"寓言先秦/魏晋"两组假二分：今本《列子》八篇＝**多源层累的开放语料库，先秦以后至东晋张湛注前写定成八篇、托名列御寇**。人物（列御寇）合理存在、素材核含先秦成分；"列子一人先秦自著今本八篇"近证伪（钉死句）；"张湛一人从零伪造"被能力反证排除；题面"寓言的朝代"是假任务，须三层分裁。

标签：层累写定 / 开放语料库 / 近证伪（一人自著）/ 品牌化 / 方向反转引用 / 思想断代三分 / 零正份额（佛学影响对断代）/ 相容待核 / 本典内部反证 / 双问正交 / 注疏倒灌。整体可信度：中高。

## 可迁移纪律

| 纪律 | 要点 |
|---|---|
| 方向反转引用 | 权威被引为支持 P 时回查原文主谓方向；"A 窃 B" 被引为 "B 窃 A" → 正份额＝0；三判据＝主谓方向核对/同篇异引对照/受益方引用检查；禁"降强度保大结论" |
| 接受史污染第三形态 | 切除（隐去声明）/ 柔化（撤回说成修正）/ 反转（保留原文翻转极性）——三者方向不同，反转最难发现，因引文是真的 |
| 思想断代三分 | "X 是 A 时代思想还是 B 时代思想"＝假任务；横向拆故事核/写定层/注疏阐释层，层间年代不传递；与"今本≠古本"（纵向版本态）正交 |
| 注疏倒灌 | 张湛注的贵虚/齐一生死/解脱玄学被读成《列子》书的思想属性＝归属层错误，注的阐释层对文本/素材核正份额＝0 |
| 能力反证归位 | "作伪者不会犯的错"只排除"一人精心伪托"，不排除"多手伪"、不证明朝代；负向排除，正向断代权重＝0 |
| 断代置信度分离 | "晚出"高置信＋宽窗（先秦后—张湛前），"具体哪朝"低置信——宽窗配高置信不矛盾 |
| 伪书钉死句 | "伪"仅指"列子一人先秦自著今本八篇"，不指人物虚构/素材无价值/思想史无价值 |
| 佛学证据归零 | 剥离反转引用与相容项后，佛学影响独立核对级证据＝0；"西方圣者/轮回/机关木人"＝相容待核、方向未定，不承担断代权重 |
