# 迦梨陀娑作者归属

## 案例概述

题面「迦梨陀娑是否真实存在？其作品是否可能为多人所作？」经全流程辩论：人物核心＝合理～高度可能但弱于护照已证；核心戏剧簇一人主导＝合理～高度可能；主干抒情／大诗同手＝合理～高度可能（略低）；全作品集单一作者＝过度宣称，外围多人／学派语料库可能；「梵语莎士比亚」＝跨文明比较品牌化；拒「全真一人／全伪多人」二元。方法主迁莎士比亚（核心簇 vs 全集），与毗耶娑／蚁垤口传史诗圣作者案机制划界。

## 方法索引

- 核心戏剧簇一人主导 ≠ 全作品集单一作者（莎士比亚纪律）
- A/B/C 三档：戏剧簇／主干诗／外围；禁 A 覆盖 B/C
- 人物「弱于护照已证」流通必带；省略＝柔化
- 「梵语X」跨文明比较品牌 → 护照／全集作者升格＝0
- 九宝／超日王轶事履历正份额＝0
- 宫廷 kāvya／戏剧 vs 口传史诗：钉机制分界；禁匀质近证伪／回赠全集护照
- 拒全真一人／全伪多人二元

## 命题拆分与分层判断

| 层 | 判断 | 置信度 |
|---|---|---|
| 人物存在 | 合理～高度可能，弱于护照已证 | 中 |
| 核心戏剧簇一人主导 | 合理～高度可能 | 中高 |
| 主干抒情／大诗同手 | 合理～高度可能（略低） | 中 |
| 全集单一作者 | 过度宣称 | 高 |
| 外围多人／学派语料库 | 可能 | 中高 |
| 「梵语莎士比亚」 | 品牌化已确认方向 | 高 |

## 过度宣称锁定句

> 过度宣称：某一单一历史个体，独自完成传统目录所归「迦梨陀娑作品集」之全部文本（含外围争议作与接受史膨胀层），且无一伪托／多手成分。

不证伪：人物核心（弱于护照）；核心戏剧簇一人主导；主干诗同手倾向；宫廷诗歌／戏剧传统。

## 结案用语

> 迦梨陀娑人物核心合理～高度可能但弱于护照已证；核心戏剧簇一人主导合理～高度可能；主干抒情／大诗同手合理～高度可能（略低）；全作品集单一作者过度宣称，外围多人／学派语料库可能；「梵语莎士比亚」为跨文明比较品牌化；拒「全真一人／全伪多人」二元。
