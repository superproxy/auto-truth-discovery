## 核心判断

拒斥"全书真/全书伪""寓言＝先秦思想/＝魏晋伪造"两组二分。本案是**五轴分层混合对象**：古料拼盘经魏晋写定、后世道藏加冕。

| 轴 | 判断 | 置信度 |
|---|---|---|
| 人物（列御寇） | 合理～高度可能，多源战国旁证，不因定本伪下调 | 中高 |
| 定本年代 | 含魏晋增窜层已确认（285 下限）；全书一次性写定待证；"秦以前连续真本"已证伪 | 中高 |
| 材料来源 | 多源古料＋晚出附益＋来源黑箱；材料层累≠定本年代 | 中 |
| 思想-叙事素材层 | 佛典输入高度可能（具体文本平行） | 中高 |
| 思想-义理框架层 | 本土道家内生为主＋魏晋玄学表述精致化 | 中 |
| 包装 | 道藏封号＋成语教材化二次品牌，已确认 | 高 |

## 关键证据锚点

- **断代下限**：季羡林——机关木人平行竺法护译《生经》(285)；《周穆王》摄取汲冢《穆天子传》(281–285)。判"含晚出锚点段落不早于 285"，非"全书一次写定"。
- **人物旁证**：《尸子·广泽》"列子贵虚"列为学派宗师、《吕氏春秋》提及、《庄子·逍遥游》列子御风；"列子"之"子"为弟子尊师之称，非功能标签（不触发功能标签零加权）。
- **翻案派错位**：岑仲勉、陈广忠、严灵峰证明"材料古/古词语"，未证明定本古——材料层证据越界当定本层判决。
- **辨伪起点**：柳宗元《辨列子》"多增窜"＋人事倒挂（子产/邓析/魏牟/孔穿/邹衍）；姚际恒首定伪；钱大昕"轮回出《列子》"；钱锺书"窜取佛说，声色不动"。

## 辩论转折点（推理者四项实质修正）

1. 定本层由"待证"上调为"高度可能魏晋写定"（接受断代下限硬锚）→ 再**收窄**为"含增窜层已确认＋一次写定待证"。
2. 撤回"张湛整理说更省备"的倾向性（标异文既可能是整理也可能是造假考据外观，H1/H2 不可分）。
3. 建立人物层独立防守（三源旁证＋名号尊称），明确不因定本伪下调；高似孙"并无其人"降 C 级。
4. 思想轴内外分裁：叙事素材（佛典输入）⊥ 义理框架（本土内生）⊥ 玄学表述（精致化）。

## 方法论增量

1. **伪书谓词分解**：判"伪"标注哪一轴，禁跨轴外推——本案主增量。
2. **断代下限≠相容**：具体文本平行（可测）vs 宽泛文化生态（相容）。
3. **材料层累≠定本年代**：古料不担保定本古，双向谬误纠正。
4. **叙事素材⊥义理框架**：可找平行者可断代，生态渐变者只定归属。
5. **作用域精确化＋主干/枝节对称**：局部锚点不撑全书一次写定。
6. **道藏包装**：宗教封号＋教材成语化切除成书争议。

## 三条下游误用禁令

1. 禁柔化回潮（定本伪不外溢到人物/材料）。
2. 禁正交挡箭牌（正交不切断下限证据→定本晚）。
3. 禁整书连坐（材料古≠全书真；部分增窜≠全书每字伪）。
