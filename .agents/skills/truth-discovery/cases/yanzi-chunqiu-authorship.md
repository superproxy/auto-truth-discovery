# 案例31：《晏子春秋》作者与成书——人物确定型言行录归属

> 结论全文：`debates/conclusions/yanzi-chunqiu-authorship.md` ｜ 方法长参考：`references/identified-figure-account-compilation.md` ｜ 结案 2026-11-25（第 49 场，辩论 4 轮，24/25 入库）

## 问题

《晏子春秋》是晏婴本人所著还是战国后人编纂？——题面预设"本人亲著/后人编纂"二分，且被历代目录"晏婴撰"题署与文学史"传记之祖"加冕强化。

## 关键事实（证据等级）

| 事实 | 等级 | 作用 |
|---|---|---|
| 晏婴真实、相齐景公、孔子称"善与人交" | S（《左传》《史记》） | 人物层锁定，对文本亲笔正份额 0 |
| 上博战国楚简《景公虐》（战国中晚期） | S（出土） | 材料下限：先秦已有晏子故事文本 |
| 银雀山汉简《晏子》103–104 枚 16 章、定县/双古堆/居延/额济纳汉简 | S（出土） | 击穿"六朝伪作"；同源异编多传本 |
| 晏子殁后事：孺子荼生年前490、晏子卒前500 | A（纪年推定）→B（全书推论） | 局部内证：某章非晏子亲历；全书亲著 B 级近证伪 |
| 刘向《叙录》30篇838章→8篇215章，外篇"疑后世辩士所为" | A（事实）/B（数字异文） | 定本化 A；外篇后增高度可能；数字 B |
| 六说互斥：淳于越/淳于髡/宾客/墨徒/稷下/反田氏 | B | 具体编者待证；"齐人/稷下相关"合理 |
| 引《诗》与《毛诗》同学派（吴则虞） | B | 写定轴旁证下限，非材料轴下限 |

## 辩论关键转折（推理者五项修正）

- **M1** 孺子荼内证由 S 降 B 组合推断，作用域收窄为"含晚出增窜章（局部已确认）＋全书亲著近证伪（B，高置信）"。
- **M2** 事件史正份额锁定默认 0；"晏子使楚"过 V0–V3 阀门失败（同池互见非分叉）；接受史/主题学高度可用不回流。
- **M3** 从不可知中拎出可判层"外篇部分章后增＝高度可能"（刘向自承＋简本对照双支持），仅原本全貌不可判。
- **M4** 定本化事实 A／确切数字 B 分判（"三十/三十八"异文，内部算术支持"三十"）。
- **M5** 思想层三分（编者注入零／采录传主言行相容线索／不可分不可判），替代一刀切零份额；柳宗元洞见与 distort 分开。

## 分层结论

人物（已确认 S）→ 事件核（默认零份额）→ 材料层（先秦流传 S）→ 写定层（西汉初高度可能）→ 定本层（刘向 A/数字 B）→ 编者层（地域圈合理、人名待证）→ 品牌层（题署＋文学加冕，品牌化）。

整体最可能解释：**以确定的晏婴为中心、战国至西汉初齐地士人据史官记录与民间传说层累编成、经刘向定本化、被历代题署"晏婴撰"并加冕"传记之祖"的言行录汇编**。既非亲笔真书，也非六朝伪作；"战国后人编纂"作为笼统归属过度简化。

## 方法论增量（可迁移）

1. **双问非对称**：人物 S 级锁定、文本亲笔仍疑——人物确定不给亲笔正份额，自著命题可被局部内证击穿，但证伪须钉最窄句并标等级（B 级组合≠S 级铁证）。
2. **三条不传递**：事件核≠亲笔、材料下限≠定本年代、编者立场≠传主学派。
3. **思想层三分**：替代"编者注入→传主零份额"一刀切。
4. **局部内证作用域精确化＋亲笔证伪等级标定**：局部不撑全书、等级分层、主干/枝节对称。
5. **出土简本校勘—断代双刃＋可判/不可判切分**。
6. **编者自述证明力分判**（行为事实 A／确切数字 B，禁自证循环与数字连坐）。
