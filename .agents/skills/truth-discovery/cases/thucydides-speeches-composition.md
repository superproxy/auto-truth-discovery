# 案例：修昔底德演讲词——方法元文本张力与代言式拟辞

> 可复用样本。方法论主干见 `../references/author-method-meta-text-fidelity.md`；通用分层见 `../SKILL.md`；完整辩论见 `../../../../debates/process/truth-discovery-debate-2026-11-17-thucydides-speeches/`，裁判报告见 `../../../../debates/conclusions/thucydides-speeches.md`。  
> **谱系边界**：与 `herodotus-credibility-bipolar-branding` 同属古典史学可信度家族，但希案争外部事件＋双极品牌；本案争**文本内部载言层／作者代言**，张力来自 1.22 自我方法声明的内部矛盾。

## 一、主题与分层判断（精炼）

- **传统宣称**：伯里克利葬礼演说是雅典民主「原声」实录，或反之「纯文学虚构」。
- **求真命题**：不作实录／文学二分；拆骨架／方法声明／措辞／论旨／体裁／包装。

| 层 | 判断 |
|---|---|
| 事件骨架（公葬＋指定演讲） | 高度可能 |
| 1.22 方法声明 | 张力元文本（非保真证书） |
| 措辞／λέξις | 过度宣称／近已证伪 |
| 论旨／γνώμη 精归属 | 意图声称＋不可核；**无弱可推断正份额** |
| 文本成品作者性 | 修氏代言式文学重构（高度可能） |
| 本篇证据类型 | 近 0 作 431 民主自我理解；近 100% 作修氏史学思想；体裁／制度史另账 |
| 近代「民主原声」 | 品牌化已确认 |
| `unquantifiably authentic` | 不可知标签（非肯定背书） |

## 二、1.22 三层切割落地

- **(a)** 意图声明成立（A）：作者声称贴近 γνώμη 与填充 τὰ δέοντα。
- **(b)** 已实现保真拒绝：无独立核验线。
- **(c)** 软约束方法论不可用：否证集近空，「禁止完全无关」不发正份额。

## 三、辩论锋利刀（教育价值核心）

1. **双约束免责拆台**：诚实免责被误读为「大意已核验」→ 钉死张力元文本。
2. **软着陆三联件拆除**：弱可推断标签粘性、0.2–0.3 伪精确、25% 社会学窗口虚账。
3. **特异性 (β)≥(α)→正贡献 0**：只挡极端全虚构，不发保真正份额。

## 四、推理者两轮地基级修正（约 10+ 项，择要）

措辞近已证伪；1.22≠保真证书；撤回大意高度可能；撤销弱可推断正份额；撤伪精确概率；本篇历史社会学窗口近 0／主用途近 100% 史学思想；(c) 不可用；弥罗斯信息源永久不可知并下调全书先验；禁止三类幽灵句式。质疑者结案：**收缩深度已匹配地基损毁**，「换壳存活」指控解除。

## 六、结案用语（可引用）

> 事件骨架高度可能；措辞近已证伪；论旨结构不可独立核验（作者有 γνώμη 意图声称，无弱可推断正份额）；本篇主要是修昔底德叙事设计下的拟辞；不得作为 431 年雅典民主自我理解或伯里克利政治哲学的核心史料；体裁／制度史另账；近代「民主原声」为二次品牌化。

## 七、方法论提取

1. 载言分裁（骨架 ≠ 拟辞）  
2. 1.22 三层切割；(c) 无独立旁证时不可用  
3. 软约束空转；特异性正贡献归零  
4. 禁止弱可推断正份额／伪精确／幽灵句式  
5. 证据类型近 0／100 分账  
6. `unquantifiable`＝不可知标签  
7. 作者自述方法元文本 ≠ 后世追认称号
