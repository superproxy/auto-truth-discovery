# 体裁嫁接拼贴（Genre Grafting / Composite Caricature）

> 案例来源：阿里斯托芬《云》中的苏格拉底（`debates/conclusions/aristophanes-clouds-socrates-distortion.md`，案例 26）

## 机制定义

喜剧、讽刺、戏仿等**反讽体裁**把"时代新潮 / 公众敌意 profile"（新式思想、习俗指控模板）具象化嫁接到一个**真实存在、公众可见**的个人名字上。产物＝三层拼接：

1. **真核（可选）**：传主可见度、公开行为细节；
2. **嫁接枝**：他人学说 / 习俗 topos / 先例案；
3. **体裁公约数**：夸张、竞赛机制、互仿互指。

## 核心判据

### 嫁接溯源三问（任一成立 → 该元素对传主"现时立场"正份额＝0）

1. **可归溯独立源头？** 挂载的思想/技艺能否归溯到他人（如《云》的自然哲学→阿那克萨戈拉—第欧根尼·阿波罗尼亚斯存货）？
2. **命中体裁 topos？** 挂载的习俗特征是否为指控模板（如"收费教辩论"=智者标准 profile）？
3. **与传主强身份标识矛盾？** 模板特征与传主可证的自标识直接冲突（如苏格拉底唯一强标识是**不收费**，申辩 19c-20a）——错挂本身=模板套用的自证。

### 辩护性回响（apologetic echo）

敌意体裁先行流通后，辩护方著作对传主"无损细节"（外貌、习惯）的呼应**不构成独立观察线**：

- 信息流＝喜剧公众形象 → 弟子辩护写作"承认无损细节＋否认有损指控"；
- **自指参照系=回响自证**：辩护文本以敌意体裁形象为参照系（《会饮》215b"照阿里斯托芬的样子像萨提尔"）即为文本内证据；
- 升格须要求**时间上先于体裁流通**的独立观察载体。

### 同池回声生态

同一体裁生态内多部作品讽刺同一对象且互仿互指（《云》《Konnos》《蛙》自指旧梗）＝**生态内持续性**证据，非独立异常连乘——异常聚类概率公式在体裁生态内失效（同池互见 ≠ 分叉）。

### 讽刺→损害→制度因果链（三档）

| 档 | 判断 | 等级 |
|---|---|---|
| 受害者自述知晓损害 | 相容待核（注意辩护策略偏置；否认内容=体裁内容清单，同源） | A⁻ |
| 体裁为主因 | 待证；长时差＋复合变量下"主因"宣称＝过度宣称 | 待证 |
| 份额比例 | 永久不可知（气氛是多元复合不可还原变量）——拒绝伪精确百分比 | 永久不可知 |

## 用途分账

- 作**接受史/公众认知镜像**：高度可用（S/A⁻）——同时代受众如何认知传主的最强证据；
- 作**传主言行史料**：默认零正份额（嫁接层与内核层一律；内核层差别只保留在"弟子承认 vs 否认"的接受史分野）；
- 后世传记采体裁台词为生平＝**混层过度宣称**；
- "歪曲 vs 忠实"二分被结构性拒绝：产物既非变形记录（无观察底本），亦非忠实夸张（嫁接可归溯他者）。

## 与相邻机制划界

| 机制 | 差异 |
|---|---|
| 道德塑形（普鲁塔克） | 选择性重塑真实材料的列传工程；嫁接拼贴是公开戏仿场合的具象化拼贴——禁匀质套用塑形模板 |
| 代言式拟辞（修昔底德） | 载言口吻归属问题；嫁接拼贴是人物 profile 归属问题 |
| 评价极性反转（希罗多德） | 后世称号机制；嫁接拼贴是同代体裁生产机制 |
| 轶事–性格循环（普氏/苏氏） | 内部选材优选；嫁接拼贴是外部元素挂载 |

## 迁移场景

政治讽刺漫画 / 网络人物 profile / 舆论画像生产：某人被当作一股潮流或丑闻的"具象载体"时，先做嫁接溯源三问，再做辩护性回响检查，最后按接受史用途分账。
