# 主编署名 × 集体编纂的份额假任务：职能层分解与协作生态归属

> 来源案例：《吕氏春秋》是吕不韦门客集体创作、吕不韦贡献几何（2026-11-25，第 51 场）。适用于"权臣/主编/机构首长署名、正文由门客/僚属/编辑集体写成"的经典（《吕氏春秋》《淮南子》《永乐大典》《四库全书》官修书、劳合社式署名手册等）。与托名型（鬼谷子/列子：人物存疑、争真伪）、人物确定言行录型（晏子：争亲笔）、开放语料库型（伊索：双问正交、边界开放）钉死机制分界，禁匀质套用。

## 一、份额分配假任务（本参考核心增量）

### 命题结构
当一部经典满足三条件：①人物确定存在（S/A）；②文本归属确定（就是这部书、无"是否他作"之争）；③正文由无名分工的集体写成（门客名单零传、分工记录零存）——此时问"某人贡献几何/占几成"就是一个**份额分配假任务**。

### 为什么它比"待证"更强
不是"数据暂时不足、将来可能补上"，而是**没有可加总的计量单位**：
- 按篇数计？——集体书篇目不可归属到人。
- 按字数计？——"人人著所闻"无逐字分工。
- 按思想条目计？——思想不可切分为"主编 X 成／门客 Y 成"。
任一单位都立刻暴露任意性。**故份额数值命题无效（命题非法），不是低置信。**

### 替代操作：职能层分解
把"贡献"拆成互不加总的职能层，逐层归属、逐层定级，**禁止重折为单一百分比**：

| 职能层 | 典型归属 | 本案（《吕氏春秋》）证据与判断 |
|---|---|---|
| 发起（为何编） | 主编/赞助人 | 政治纲领意图声明成立（A《序意》＋B《史记》） |
| 资助／组织 | 召集人、出资人 | 高度可能～已确认（B；同源双证折单柱） |
| 宗旨裁定 | 主编意图 | 意图声明 A 级成立；全书贯彻相容待核；单一思想主旨近证伪 |
| 执笔 | 集体为主 | 门客为主高度可能（单柱 B）；主编逐篇亲笔近证伪 |
| 署名 | 主编姓氏冠名 | 主编品牌化已确认 |
| 包装 | 出版/教材/大众 | 政治定价＋教材加冕已确认 |

### 与"反伪精确"家族的关系
- 《尔雅》"解决作者争议 ≠ 选一个护照名"——**选名版**假任务。
- 《鬼谷子》三不可锚（人物/年代/材料不可定）——**断代版**不可锚。
- 本案"贡献几何"——**份额版**假任务。
三者同属一条主线：识别提问本身的非法结构，而非在给定框架内填一个更精确的数。

## 二、主编主持的协作生态写定本（归属阶梯新落点）

人物确定、文本归属确定，但作者性既不在单一个人（非亲著）、也不在无主语料库（伊索型开放边界）——而是分布在**协作生态**（集体执笔）与**编订**（主编组织/裁定）两层。整体落点＝**主编主持的协作生态写定本**（editor-presided collaborative-ecology redaction）。归属阶梯：人物（已确认）→ 事件 → 编订（合理、身份不可定）→ 协作生态（高度可能）→ 品牌（已确认）→ 改写（相容待核）。

## 三、四条对称不传递（本案版）

前三条向下切、第四条补反向，双向对称防两端越界：
1. **资助／组织 ≠ 执笔**：出资召集不等于逐篇写定。
2. **裁定意图 ≠ 全书贯彻**：(a) 意图不传递为 (b) 贯彻/(c) 执笔。
3. **主编署名 ≠ 思想独归**：冠名不等于每篇思想可归一人。
4. **集体执笔 ≠ 主编无思想贡献**：不得以"集体"反推"主编无与"（防黄震/卢文弨"固无与也"式抹除）。

## 四、双向品牌化（署名膨胀 vs 署名抹除互相续命）

- **膨胀端**：大众/教材"全书皆主编一人智慧""字字不可改"（本案＝"一字千金完美之书"）。
- **抹除端**：疑古者"主编固无与也"（本案＝黄震、卢文弨）。
- **机制**：任一端受质疑，另一端即被搬出当"纠正"，两端互相续命，压平中间协作生态。
- **裁判**：两端皆过度宣称；回到原始目录学分判（本案《汉志》"秦相吕不韦辑，智略士作"——"辑/作"本已分开）与职能层分解。

## 五、书名态三分（对象偷换检查）

同一书多个名称可能对应不同署名机制，压成一层即对象偷换：

| 书名态 | 署名机制 | 品牌化判断 |
|---|---|---|
| 《吕氏春秋》 | 姓氏冠名＋"春秋"史典自号 | 主编品牌，借史典权威 |
| 《吕览》 | "览"体例简称、书目简称 | 中性简称，无独署强化 |
| 《吕子》 | 诸子化升格（抬到老庄作者经典位） | **二次品牌化**：制造"一家之言作者"假象 |

## 六、主编序元文本变体（意图声明三层切割）

主编为集体作品立的纲领（本案《序意》"上揆之天，下验之地，中审之人"）：
- 只锚 **(a) 意图声明成立**（A 级元文本）。
- **(b) 全书贯彻**：无逐篇核验→相容待核；且 **纲领语义决定 (b) 判词**——读作"方法论准则"则相容待核，读作"单一思想纲领"则近证伪（text multipolar 不支持）。
- **(c) 逐篇执笔**：零正份额。
- 与"史家拟辞/作者自述方法论"分界：后者张力是"保真 vs 裁量"，本变体张力是"主编为集体作品立纲领"——纲领证裁定意图，不证执笔事实。
- 《序意》残文、仅十二纪殿尾而非全书序（四库提要、杨树达）→ 连身份都不稳，更扛不起执行证明。

## 七、锚点多解伪精确

同一 A 级文本锚因换算/解释规则不同产出多解时（本案"维秦八年，岁在涒滩"→前 241/前 239/前 238 及郭沫若否定推算），分歧不在证据而在**规则本身不可考**（方法性不可得）。收口＝给**窗口**（前 241–前 239）＋**单一年份永久待证**，禁任一派站队。与"晚出证据共柱坍缩"（鬼谷子）区分：共柱是多条证据共享前提，本条是单锚多解。

## 八、材料外溢 → 篇序反向重塑

互文方向稀有可定案例（本案郑玄《三礼目录》："《月令》本《吕氏春秋》十二月纪之首章，礼家好事抄合之"）：本书材料被后世经典（《礼记》）采入 → 反过来催生后世以经部标准重排本书篇序（《史记》"八览六论十二纪" vs 高诱序"十二纪八览六论"）。label：材料外溢已确认；篇序反向改造相容待核；改造者不明。此链不直接回答份额，但解释文本形态为何被后世重塑。

## 十、收口模板
"以〔主编/权臣〕姓氏冠名、正文由〔门客/僚属〕集体写定、经后世整理重塑篇序、被〔膨胀端品牌〕与〔抹除端质疑〕双向拉扯的**主编主持的协作生态写定本**。'某人贡献几何'为份额假任务，有效答案＝六职能层逐层归属；四条不传递双向防错；人物与文本归属确定，但执笔分配、思想渗透份额、单一年份均永久待证或不可分层不可判。"
