# 阴谋论解释闭环审计（判据簇）

> 归属：现代科技/公共事件真伪 + 阴谋论叙事的副对象审计。判据簇，非新轴——复用「红旗清单 + 证据方向倒置 + 不可证伪性」三工具，不新设轴桶。
> 首案：`cases/moon-landing-real-or-hoax.md`（第 62 场）——美国载人登月 vs 登月造假论。

## 一、适用问题

题面为「X 事件是真是假」，且附着或隐含一个「X 造假论/阴谋论」叙事。这类题是**双对象**：

- **主对象**：事件本体（载人登月、登月造假、疫苗、九一一……），用常规证据分级可锚定。
- **副对象**：围绕事件的「造假论」叙事，本身是一个需要被审计的论证结构，不是可被直接真/假二分的普通主张。

若只审主对象、漏审副对象，会把「不可证伪的叙事」误当「可证伪主张」处置，标签用错；若只审副对象、不锚主对象，会滑入「无真相」虚无。

## 二、核心判据

### 1. 处置标签二分（先判对象类型）
- 对**可证伪主张** → 用「已确认/已证伪」。
- 对**不可证伪叙事/信仰闭环** → 用「不可证伪伪科学叙事 / 品牌化」，禁用「已证伪」（已证伪只能作用于可证伪主张）。

**操作**：先问「该主张能否被某个可能的证据否证？」若能 → 可证伪，按证据裁判；若不能（任何反证都被吸收）→ 不可证伪，转叙事处置。

### 2. 解释闭环（hermetic explanatory closure）——阴谋论结构核心
阴谋论区别于普通错误主张的标志：**反证被无限吸收**。任何 S 级反证都被「那也是假的/被收买了/被PS了」吞进框架，闭环自我维持。

- 识别即定性：一旦出现解释闭环，对象即从「待证伪」转为「不可证伪叙事」。
- 判据簇意义：解释闭环不是「无法反驳」，而是「反驳无意义」——它不是被证据支持，而是对证据免疫。

### 3. 证据方向倒置
造假论常把**真实特征的物理表现**倒置为「造假证据」：
- 登月照「无星星」＝短曝光+高亮度（真实拍摄特征），被倒置为「棚拍忘了挂星星」。
- 「国旗褶皱」＝横杆支撑（真），被倒置为「有风」。
- 与「缺沉默当剪影」（把沉默当正面证据）、「引文极性反转」（把权威原意引反）同属**证据方向倒置**家族，须逐条核方向。

**反证逻辑**：若真造假，造假者反而会「正确地」挂星星、让旗帜自然下垂——正是这些「不自然」细节支持真实。方向倒置一旦识别，疑点本身即从反证转为旁证。

### 4. 强度不对称陷阱（对称陷阱）
不能用「双方都在宣传/各有动机」模糊证据强度差：
- 主对象常握 S 级物证（月岩、角反射器、多国成像），副对象常只有「照片疑点」级 D/E 材料。
- 也不能因反感官方/冷战宣传，就默认「反官方叙事更真」——两条线都是意识形态战场，但强度悬殊。

**操作**：把「动机结构」与「证据强度」分开记账；动机只能解释「为何有人相信」，不能替代「证据是否成立」。

### 5. 事实⊥包装分层
现代公共事件常叠一层宣传/符号包装（名言象征、英雄叙事、民族自豪）：
- 宣传层的存在**不否证**事实层；
- 事实层的真**不担保**宣传层「每句字面真」。
- 二者是独立命题（复用「观察保真⊥外推有效性」「事实⊥评价」双问骨架）。包装层按「品牌化/符号建构」处置，不参与事件真伪裁判。

## 三、操作化步骤

1. 锁定主对象（事件）与副对象（造假论叙事）两个裁判单元。
2. 主对象按常规证据分级锚定（S/A/B/C/D/E），给「已确认/已证伪/高度可能/待证」。
3. 副对象先做**可证伪性测试**：给出「何种证据可推翻它」，看论证是否解释闭环化。
4. 若闭环 → 定「不可证伪伪科学叙事/品牌化」，并点名解释闭环机制。
5. 逐条核「疑点」的证据方向，识别方向倒置（真实特征被读成造假证据）。
6. 动机结构（谁获益）与证据强度（多少S级）分开记账，设防对称陷阱。
7. 若事件叠宣传层，做事实⊥包装分层，包装层切出真伪裁判。

## 四、与其他轴/判据簇的分界

- **vs 内容真实性轴（存在性⊥保真性）**：那是问「技术/工艺记载是否实有」；本案问「事件本体是否发生」，对象是事件非记载。
- **vs 来源大轴三变体（可靠/份额/取向）**：那是问「知识从哪来」；本案不问来源。
- **vs 评价放大轴**：那是问「后世如何评价/是否夸大」；本案副对象是「叙事本身真伪」，非评价放大。
- **vs 品牌化（古典域）**：本案「反建制品牌」是阴谋论叙事的品牌化，机制是解释闭环+证据方向倒置，区别于古典域的「归名到权威名字」。
- **复用（非新设）**：红旗清单（孤证+完美叙事、选择性留存）、证据方向倒置家族、不可证伪性、事实⊥评价双问骨架——本案是这些既有工具的**跨域（现代公共事件）应用**，不构成新轴。

## 五、边界

- 本案判据簇针对「现代科技/公共事件 + 阴谋论」双对象题；古典文本/人物域的「伪书谓词」「作者谓词」等仍走既有轴，禁匀质套用。
- 「不可证伪」是叙事的**结构特征**，不等于「该叙事的内容全错」——叙事里可能混有真实成分（如政府确实有过宣传），但「造假论核心主张」作为整体不可证伪，须整体按叙事处置，逐条核其内部真实颗粒不改变定性。
