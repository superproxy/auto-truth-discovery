# 来源认知操作审计 —— 观察保真 ⊥ 外推有效性

> 首建案例：盖伦「医学著作多少基于实际解剖、多少基于动物类推？」（2026-11-26，第59场）
> 定位：**新轴——来源认知操作轴**，与来源大轴三变体（可靠/份额/取向）、接受端评价放大轴、内容真实性轴均正交。问的是"知识怎么获得＋外推边界在哪"，不是"来源可靠吗/构成占比/取向/评价/内容真不真"。**复用双问正交骨架，但轴对象全新，不并入既有任何轴桶。**

## 一、轴定位：与前案的正交表

| 轴 | 问的问题 | 代表案 |
|---|---|---|
| 来源·可靠轴 | 来源整体可靠吗（六轴复合） | 说文解字 |
| 来源·份额轴 | 单作者文本内原创/抄录构成占比 | 水经注 |
| 来源·取向轴 | 知识来自亲身实践还是文献汇编 | 齐民要术 |
| 接受端·评价放大轴 | 后世如何评价/夸大 | 梦溪笔谈、帕拉塞尔苏斯 |
| 内容·存在性⊥保真性 | 所记技术是否实有、记载能否复现 | 天工开物 |
| **来源·认知操作轴（本案）** | **知识从哪种认知操作获得（一手观察 vs 推理外推），外推在哪一段失效** | **盖伦** |

要点：本案的"观察≠理解"（天工开物案）是**概念辨识错误**（看得到现象分不清原理），本轴是**观察真但外推到新域失效**——机制不同，禁混用。

## 二、元层两道非法命题（先拆再判）

1. **份额假任务**："多少基于 A、多少基于 B"——先看有无可加总单位。著述数量三说（131/约300/500+）、散佚严重、一篇之内多来源缠绕、无分工账 → 分子分母皆不可构造 → **命题非法（比待证更强）**，收口弃用比例/占比，改机制分层＋分层定性。承《吕氏春秋》《水经注》份额假任务家族，但本案非法原因＝**同一认知链两段不可切分**。
2. **假二分/范畴错置**："实际观察 vs 推理外推"常被压成两个互斥来源桶。实际二者是同一认知链的**前后两段**：`一手观察 → 外推应用 → 陈述成文`。不存在"这段纯观察、那段纯外推"的切分点——每个外推结论以某个观察为原料，每个观察在著作中以外推后的陈述面目出现。拒两端站队。

## 三、核心：观察保真 ⊥ 外推有效性正交双问

- **观察保真**：一手观察/实验是否真的发生、内容是否可靠。
- **外推有效性**：把该观察迁移到目标域（另一物种/另一场景）是否成立。
- **双向禁互推**：
  - 观察真实 ↛ 外推有效（实验层全对不担保人体层对）；
  - 外推失效 ↛ 观察虚假/造假（目标域错不否定来源域观察真实，更不构成诚信问题）。
- **错误定位纪律**：错误成簇于外推层时，明确"错误在外推层、不在观察层"；禁把外推错误回写成"观察粗糙/造假"（虚无化），也禁因观察可靠回赠外推正份额（护短）。

## 四、外推有效性分层：物种保守性判据 + 判据降级纪律

- **保守性判据**：外推有效性取决于所推断结构在源域与目标域之间是否**同源保守**（共同祖先保留的基本结构）而非**域特异分化**的结果。
  - 保守层（外推有效）：骨骼大体、脊髓节段、脑神经走向、肾与输尿管机制、动脉含血——跨物种同源。
  - 特异层（外推失效）：rete mirabile（有蹄类颅底特异）、肝叶数、子宫角数、肋骨数、下颌骨、心脏间隔孔——域间分化结构。
- **反例条件须显式**：若在保守结构上出现系统性错误、或特异结构上全对，则判据失效。
- **M10 判据降级纪律（通用，跨案例）**：凡判据由**已知结果归纳**而来、缺**独立注册的前瞻验证**（验证集与归纳集同源／拿同一批例证既归纳又宣称"经独立检验"＝同一数据两用），则：
  - 由"可复核定律"降为**"强解释假说"**（解释力高、前瞻未证）；
  - 置信度如实下调（序数量化、非贝叶斯后验，如 0.90→0.80），表述改**条件式**（"按此判据则…"，禁"必然/已证"）；
  - 写明"何种前瞻验证可升回"（预注册预测被新证据验证）。
  - 适用武器库全部归纳判据；禁伪精确数值固化。

## 五、观察—文本分层隔离（R1–R4）

一手观察到成文之间有多道传递，证书**发到哪层就停在哪层**，上下行双向禁：

| 档 | 对象 | 本案等级 |
|---|---|---|
| R1 观察/实验行为层 | 确实亲手做了（行为存在性） | A（B佐证） |
| R2 发现内容层 | 结论本身（可被现代独立复现） | A/B |
| R3 转写层 | 听写者记录→成文 | C/D |
| R4 现存载体层 | 阿拉伯/拉丁译本链逐字忠实 | B（译本）/C（逐字） |

- **规则**：R1/R2 可靠不自动上行给 R3/R4 逐字忠实；R4 不确定不下行否定 R2 内容。
- **正向特例（承载体/内容分离）**：当 R2 结论由**外部独立复现**支撑时，其可靠**不依赖**文本传递链——"载体不可核但内容可外部复现"＝载体/内容分离的正向特例（第欧根尼案 V0–V3 是反向：载体不可靠、嵌入文献靠内证＋外证升骨架）。此为同一家族的反向用法，不新设机制桶。
- 与"接触≠摹录可靠""标示≠忠实""引用≠亲见"同族——整体信用不自动传导到传递链。

## 六、人体/目标域有限窗口隔离三问

当存在"有限直接观察窗口"（如角斗士伤口、偶然尸检）时：

- **存在性**：窗口存在过 = 高度可能（B）；**比例性**：对"目标域描述可靠"正份额＝0（举证责任层，非"确证没有"，禁强断言）。
- **归属隔离三问**：①该结构是否在窗口可暴露范围？②该结构是否需打开体腔/清洁标本才能观察？③有无原文明确自述"我在目标域见到 X"？三问全过才给窗口归属正份额。
- 本案命门结构（rete mirabile/肝叶/子宫）全在②（窗口不可及）——这正是"窗口存在但不救深层描述"的原因。双向禁互推：窗口存在不给人体的深层描述发证书；主体是外推不抹掉窗口对浅层结构的相容贡献。与"阙如"零足迹空转型、"反向检验足迹"存在性vs比例性族同构。

## 七、理论框架独立第三来源 + 接受端另账

- **理论框架第三源**：目的论/体液/灵气一类框架是**继承＋推理**的独立来源，既非一手观察亦非外推——不许塞进"观察 vs 外推"二分，也不许拿它给观察/外推层背书。
- **接受端另账**：后世加冕（"医学教皇/之父"）与负面标签（"拿猪当人/错1500年"）归评价放大轴，双端强度不对称如实照报，不穿透来源层判断；禁反向对称陷阱（不得因负面也是构造给外推背书）。

## 八、判断标签与分界

**标签**：`份额假任务` · `假二分/范畴错置（观察→外推同一链）` · `来源认知操作轴` · `观察保真⊥外推有效性正交双问` · `观察—文本分层隔离（R1–R4）` · `载体/内容分离正向特例` · `物种保守性判据（强解释假说）` · `保守层有效/特异层失效` · `错误定位外推层` · `人体窗口（存在性·比例性零·隔离三问）` · `理论框架独立第三来源` · `三层混合对象`

| 范式 | 对象 | 本轴区别 |
|---|---|---|
| 来源可靠轴（说文解字） | 来源整体可靠吗 | 本轴拆链内两段，不打包 |
| 内容轴（天工开物） | 技术实有/记载复现，"观察≠理解" | 本轴是观察真但外推失效，非概念辨识 |
| 载体/内容分离（第欧根尼） | 二手载体中嵌入文献真伪 | 本轴 R1–R4 是正向特例（内容可外部复现故升），反向用法 |
| 评价放大轴 | 后世评价 | 本轴另账，不侵入来源判断 |
| 双问正交家族（人物⊥文本等） | 各种双问 | 复用骨架，轴对象为"观察⊥外推" |

## 九、检查清单

1. "多少 A 多少 B"是否先判份额假任务（可加总单位）？
2. "A vs B"是否假二分（同一认知链两段）？
3. 观察保真与外推有效性是否拆成双问、双向禁互推？
4. 错误是否定位在外推层、未回写成观察造假（虚无）或以观察可靠回赠外推（护短）？
5. 外推分层判据有无反例条件、独立检验集？同源/同一数据两用则降级为强解释假说、条件式、写明升回条件？
6. 观察—文本是否 R1–R4 分层、证书停本层、不上下行？
7. 有限窗口是否守存在性/比例性零/归属三问？
8. 理论框架是否独立第三源、接受端是否另账？
9. 与来源三轴/内容轴/评价轴是否钉死分界、禁匀质套用？
