# 宗教文本体裁与身份声明审计（判据簇·第三次非零残差·非新轴）

> 定位：判据簇，挂靠归属阶梯「编订/品牌层」＋「张力元文本层」，**非新轴、不新设轴桶**。抽掉测试连续四场零残余（维特鲁威→普林尼→斯特拉波→摩西出埃及）后，JEDP 案首次非零残差、耶稣案第二次，**本案第三次非零残差**。三处残余按纪律降判据簇，与盖伦案「防过度保守吞真实增量」配对保管：真实增量不得压没，也不得借残余立新轴，措辞不得把簇内子判据标成「通用判据·教科书级」造成两头占。
> 案例：`cases/gospels-eyewitness-vs-community-construction.md`（案例48）；结论 `debates/conclusions/gospels-eyewitness-vs-community-construction.md`。

## 一、适用与轴位

宗教经典被问「是目击者记录还是后世共同体的神学建构」类命题。题面是**假二分**：两个复合谓词各捆三义——
- 「目击者记录」＝①作者本人是目击者 ②文本逐字转录目击内容 ③体裁属史学实录；
- 「共同体神学建构」＝①传承在共同体中流动 ②神学塑形 ③从零虚构。

必须先拆谓词、逐层独立定性，禁二选一。**人物层（经典主角是否存在）若已由前案钉死则不重开**——本案直接继承 `jesus-existence-nonchristian-sources`（案例47）的「高度可能＋弱于护照」，专注文本层，避免与上场重复搜证。

## 三、子判据一：体裁谓词部分失效（残余①）

古代传记（bios）≠现代史学实录。用「目击者逐字记录/史学实录」的现代史学 regime 套古代传记体裁，谓词**部分失效**——「使徒亲笔目击录」＝过度宣称。须先判体裁、再判载言保真，禁以体裁期望直接定保真等级。此与「体裁范畴错置」（注疏体原创/抄录谓词失效）、「作者性纯度」（compiled 署名≠逐字自撰）同族但对象不同：本条针对**传记体裁 vs 史学实录**的谓词错配，且叠加**作者身份声明**这一新对象面（载言分裁原对象仅为史家拟辞）。

## 四、子判据二：身份声明元文本分层（残余②）

张力元文本既有对象是「方法声明」（修昔底德 1.22）与「来源声明」（说文解字「信而有证」）。本案扩展至**作者身份声明**——「我是否目击」「谁为谁作保」。分层纪律：
- **A 级元文本语法事实**：序言/结语白纸黑字写了什么（如路加 1:1-4「那些从起头就是目击者和传道的人…传给我们，我也…写给你」的 κἀμοὶ 语法位置；约21:24「这门徒…作见证且写下，我们知道他的见证是真的」的群体 we）。
- **B 级解读结论**：「作者自置于接受者之列、非目击者」是学界主流读法——consensus 是**证据政策信号**，不是 S/A 级铁证（承 JEDP「共识＝信号层非锚」、耶稣案「共识≠逐条核查」跨域复用）。禁把 B 级读法读成 A 级铁证（共识回流红旗）。
- **(a)≠(b) 硬隔离维持**：元文本存在（a）不发「作者即目击者」证书（b）。
- 给可失败判据：若发现「我曾亲眼看见」第一人称自述，则「作者非目击」被推翻。
- **群体保证（约21:24 型）**：we 为一个未具名权威人物作保，锚定「群体认定此传统出自一权威目击者」，对「作者＝某具名使徒本人」零正份额——非署名证书。

## 五、子判据三：外部附加名反向变体（残余③）

亲历署名审计（普林尼 ipse vidi）针对**自署亲历**（作者自己声明亲眼见过）。本案是**匿名文本＋后世（2世纪）附加使徒名**——署名从外而非内发，方向相反：
- 四福音成书时匿名流传，名字由 Papias（约110–130，经 Eusebius 二世纪后保存）→Irenaeus（约180，以四方风论证「只能有四福音」）附加。
- 附加名对「使徒亲笔」正份额＝**0**，仅锚「权威锚定行为发生」（品牌化）。
- 与「标题形式一致（按照马太/约翰…）」的抄本证据（A级）配合：格式证据只证匿名流传＋题名后加的结构，不证作者身份为真。

## 六、子判据四：源头目击者射程钉死（`eyewitness-source-scope-zero-share`）

「传统源头曾有目击者参与口传」＝窄命题高度可能（B+，跨范式硬核——Ehrman 与 Bauckham 均认，分歧只在传递机制），但对「文本是目击者记录／逐字实录／使徒亲笔」正份额＝**0**——跨轴借用禁令的新应用（承存在性⊥来源、敌意旁证两账分账）。防两端越闸：
- **上行闸**（拦护教）：「源头有目击」＋「载言骨架可信」≠「文本逐字实录」／「使徒亲笔」／「历史证明神性」——据跨轴借用禁令＋事实⊥意义正交＋相容≠核对，越闸零正份额。
- **下行闸**（拦虚无）：「作者非目击」＋「记忆可塑」≠「从零虚构」／「人物不存在」——据塑形≠虚构＋弱否定非正面证据＋前案人物层已钉死，越闸零正份额。

## 七、子判据五：窄兼容 vs 全面兼容＋文学依赖双向射程

- **窄兼容⊕文本层竞争**：跨品牌兼容性判定不可滥用，须逐层判兼容/竞争。Bauckham「源头有目击」与 Ehrman「传递可塑」在**源头层窄兼容(B+)**；但其文本层生成模型（对观「quite closely 基于目击见证」／约翰由目击者写 vs 匿名据数十年口传编写）**正面竞争**、不可同时为真（B/B，皆修正中）。把「窄兼容」说成「全面兼容」＝用和谐姿态柔化实质冲突（「承认小错坚持大结论」变体）——本案推理者 M1 主动撤回「全面兼容」即此教训。
- **文学依赖双向射程**：对观文学依赖（马可优先＋Q 假说）对 Bauckham 文本模型＝负证（削弱「独立目击见证」），对 Ehrman＝**中性偏相容而非正证**（文学依赖≠记忆失真，不同维度）——强度诚实记账，禁给任一端发证书（承对称陷阱禁令）。Q 源本身无抄本、有 Farrer/Griesbach 竞争模型＝范式内模型 B 级，禁当事实用。

## 八、收口与反模式

收口＝八层分裁（人物层不重开／体裁 bios／作者匿名＋2世纪附加名／身份声明元文本／对观来源范式模型／载言代言式重构／神学塑形／正典包装），整体置信度针对**裁判框架**而非任何具体断言。

**反模式**：①把源头目击软承重为文本层证书；②把 consensus 读成 A 级铁证；③把「作者非目击/记忆可塑」偷渡成「从零虚构」；④用全面兼容柔化文本层竞争；⑤借第三次残差新设轴桶或措辞两头占（把簇内子判据标「通用判据·教科书级」）；⑥把真实残余压回判据簇当没发生（吞增量）；⑦匀质套用摩西双对象题/JEDP 范式题/耶稣敌意旁证题（对象不同，须钉死分界）。

## 九、分界

- 与 `religious-origin-narrative-dual-track-audit`（摩西出埃及）钉死分界：彼为人物存在⊥事件考古双对象题，本题人物层已结案不重开、专注文本体裁/身份声明。
- 与 `academic-paradigm-audit`（JEDP）分界：彼问正典作者归属/成书模型，本题问文本体裁/载言保真/目击者声明——仅复用「范式内模型 vs 跨范式硬核」工具。
- 与 `author-method-meta-text-fidelity`（修昔底德）、`autopsy-claim-audit`（普林尼）、`secondhand-compiler-transmission-hub`（第欧根尼）分界：三者对象分别为史家拟辞／自署亲历／单一署名编者，本题为传记体裁＋身份声明＋匿名外部附加名＋对观编辑网络，机制不同禁匀质套用。
