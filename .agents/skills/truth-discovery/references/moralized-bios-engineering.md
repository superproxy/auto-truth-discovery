# 道德化传记／bios 工程分裁

> 专题长参考。首案：`debates/conclusions/plutarch-parallel-lives.md`（普鲁塔克《平行列传》，2026-11-17）。  
> 与 `author-method-meta-text-fidelity.md`（载言／方法序张力）、`attribution-pollution-gradient.md`（单叙事偏见）、`bipolar-reputational-branding.md`（外加相反称号）分工：本案专治**整部道德化列传工程**被压成「历史／道德寓言」假二分。

## 一、问题意识

「历史还是道德寓言」是假二分。作者公开写 βίοι／性格示范时，中间地带＝**道德塑形已确认**、**不是**劝诫寓言式全盘虚构、**也不是**无过滤正史。裁判须拆层，禁止站队。

## 二、道德塑形 ≠ 寓言虚构

| 判据 | 说明 |
|---|---|
| 塑形成立 | 选材、省略、动机优待、示范编排以德行主题导向 |
| 标签降级 | 「道德寓言」作整体本质定性＝过度压缩 |
| 零信用回潮 | 「不是寓言」**禁止**回赠事件史／轶事保真正份额 |
| 探索性道德主义 | ＝阅读伦理；对史实保真**零**正份额 |

## 三、3a 发生坐标 ≠ 3b 叙事化骨架

- **3a**：人名、官职年序、战役／败亡等结局标签 → 默认「相容待核／个案升格」；窄分叉（铭文／当事人文书／钱币等）仅升格极窄坐标。
- **3b**：比例、场面、归咎、动机链、道德因果 → 归塑形／设计计价；对「历史讲述」高可疑。
- **禁回流**：3a 升格不覆盖 3b；禁止「发生过 → 如此被讲述」。
- **与载言分裁接口**：人事核 ≠ 载言成品拆骨架 vs 措辞；本条拆坐标标签 vs 讲述结构。

## 四、比较装置设计污染

强制平行配对、篇末 Synkrisis／排行终裁 → **设计污染／强制可比性**。终裁层对「历史人物客观对照／传主实际德行」正贡献＝0。硬不对称仍强行可比 → 强化设计优先，不得反证「比较反映史实」。

## 五、同作者跨体裁双标

批评体／方法论文具备较严史学规范，传记／示范工程中选择性停用 → **双标成立并计价**。禁止「体裁不同」免检；体裁差可解释动机，**不**恢复约束硬度。主要下调 3b／轶事，不自动归零窄 3a。

## 六、显式弃权下的当史引用（B1–B3）

作者声明写生平而非历史、可略大战、轶事见性格时，当史引用比无弃权正史**更严**。任一触发 → 否决「当史引用」：

- **B1**：单独作事件／年表权威，且未并引独立分叉、未提示体裁限制。
- **B2**：将「战役／官职坐标」与「性格金句／动机／德行类型」打包为同一史实单元。
- **B3**：将配对／比较终裁引用为客观对照或传主实际德行。

## 七、互补双重品牌（≠ 双极相反称号）

「正史替代／史宝库」↔「道德寓言／性格圣典」两侧包装互相供养；任一侧受质疑滑向另一侧。常切除体裁／方法元文本。与双极品牌化分裁：后者＝**相反**称号各制度化；本模式＝**互补**过度宣称制造假二分。

## 九、结案模板与重开

**结构假说用语**：道德化平行列传／bios 工程；Credible ≤ 最弱承重柱；拒假二分。

**重开条件**：近同时代独立线在具体轶事论旨结构上收敛 → 个案重开轶事正份额；更多分叉审计 → 扩 3a 白名单（仍不回流 3b）；第二条同等明示「知争议仍择合性格」→ 可将「性格压年表」从强嫌疑升为系统政策。

## 十、帝王轶事—类型学变体（罗马侧）

> 变体案：`debates/conclusions/suetonius-twelve-caesars.md`（苏埃托尼乌斯《十二凯撒传》，2026-11-18）。  
> 与普案同族（轶事零配额、互补双重品牌、相容待核笼统层**复用、不重写**）；缺口在近档制度光环、文书声称分裁、升格阀门操作化。无同等 Synkrisis——隐性十二帝类型对照＝**待证偏置假说**，不进承重。

### 10.1 「史料／八卦」假二分

与「史／寓言」同属互补双重品牌族；装置关键词不同：rubrics 主题轶事库＋近档光环 vs 显式 bios 弃权＋平行配对。拒斥整书站队后，再独立裁判 rubrics、公开骨架阀门、文书 (a)/(b)、私密轶事零配额与声誉史用途。

### 10.2 职位光环 ≠ 保管链

曾任秘书处／近档／近权力＝**制度可能光环／加严触发器**；对升格权重＝0；接近度只加严不加分。无显式「从档抄出 X」与保管链时，禁止读成档案通行证或「大体真实」半证书。

### 10.3 文书 (a)/(b)；引用 ≠ 亲见

正文信件／遗嘱／元老院等引用须拆：**(a)** 公共文书回声＝相容待核／可走真正分叉升格（**禁**职位加权）；**(b)** 私人文书／对话／场景道具＝事件史默认零正份额。「他写道／据说有信」alone ≠ 亲见保真。对象＝文书声称层，**≠** 方法序张力元文本 (a)(b)(c)。

### 10.4 升格阀门 V0–V3；相容 ≠ 锚

缺一不可 → 不得升格；**默认关闭**。**V0** 禁职位／弱制度进权重；**V1** 论旨结构重合（禁「同帝同主题」模糊相容）；**V2** 真正分叉（同生态互见默认同池 ≠ 分叉）；**V3** 句级封顶（禁穿透私密／动机／属性）。未过阀／未抽样 → 事件史正份额**固定为 0**。**相容 ≠ 锚**：锚＝仅已过阀门之窄公开坐标／文书大意。表格式抽样只示范阀门，禁读成全局可靠比例。

### 10.5 谓词隔离；声誉史不回流；禁柔化句

未过阀门的「残暴／失政／变态暴君」等本质谓词禁止作公开骨架（层 3）承重；丑闻簇不得洗入坐标层。声誉史／主题学／接受史＝高度可用，**禁止**买回事件史正份额。摘要写「分层可用、丑闻宜谨慎」而未锁定声誉史等用途 → 下游柔化，退回改写。
