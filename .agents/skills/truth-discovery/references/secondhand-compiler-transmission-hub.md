# 二手编纂者转引枢纽：来源散佚、n=1 幸存与嵌入文献的载体/内容分离

> 适用：一部经典由一名"不加批判"的二手编者（doxographer／类书编者／口传整理者）保存，其署名来源多已散佚，大众把它压成"可靠宝库 vs 八卦"二分。典型：第欧根尼·拉尔修《名哲言行录》。
> 划界：≠ `author-method-meta-text-fidelity.md`（第一手作者自述方法论张力）；≠ `survivorship-pair-bias-and-defense-mapped-texts.md`（n=2 双峰+申辩映射）；≠ `moralized-bios-engineering.md`（道德塑形）。本案"不加批判"是**公开的方法特征**，不是隐藏塑形；幸存形态是 **n=1** 而非双峰；核心张力是**嵌入的一手文献可脱离载体独立鉴定**。

## 一、总原则：拒绝整书站队，拆四问

面对"某二手编纂者的记载可靠吗"，先拒绝"整书可靠/整书八卦"二分，依次问：
1. **来源层**：他署名的来源今天可核吗？署名给可靠性加权吗？
2. **叙述层**：轶事、生平事件、师承谱系——是观察还是建构？
3. **嵌入文献层**：书中是否保存了一手文献本体（书信/遗嘱/法令/目录/残篇）？它能否脱离编纂者被独立鉴定？
4. **文本层**：现存抄本是否独立见证？还是单一 stemma？

## 二、署名来源透明黑箱（cited but lost）

- **引用透明性（citation transparency）≠ 可核验性（verifiability）**。编者给每条材料挂上来源名（"某某说"），制造严谨外观；但来源一旦散佚，署名只能证明"存在一个被提及的权威名"，不能证明该来源说了什么，更不能证明编者忠实转述。
- **署名对材料真实性正份额＝0**；唯一合法用途＝**目录学线索**（提示某来源名存在/被提及）。
- "并列异说/记录分歧"同样不可核——无法验证编者忠实记录还是自己编排；降为"相容待核"，不作保真证据。
- **输出禁令**：禁止"因为他标了来源所以更可信"的任何加权；"透明黑箱"仅作描述标签，不携带可靠性含义。
- 定性为**方法性不透明**而非欺诈——避免把缺陷道德化（"八卦之父"式），但也绝不因此减损不可核性。

## 三、n=1 幸存者偏差（唯一来源）

- 当对大量对象编者是**主要甚至唯一来源**、后世转述皆源自他：**同源互证＝0**，"多源一致""后世都这么记"只是同一源头的回响，不是独立验证线。这是幸存双峰（n=2）的极限形态。
- **杀伤力分层**：对轶事/生平事件/师承陈述——事件史零正份额（同 bios 案）；但**不自动穿透嵌入一手文献层**。
- **层外窄例外**：嵌入文献一旦存在，其真实性由文献本体+外部独立旁证决定，核验线不在编者的转述链上——故 n=1 不使其失效。禁把 n=1 外推成"全书一切皆回响"。
- **功劳归属**："某编者记载较正确"是柔化句——若核验收益来自嵌入引文+外部旁证，则可靠性功劳归**材料与外部检验线**，不归编者可信度。改为："其保存的嵌入文献可被外部独立检验，部分通过。"

## 四、传承谱系建构（diadochai 作为分类装置）

- 学派的"传承两分"（如爱奥尼亚/意大利）、师承链（谁师从谁），多为**后世合法性追认**与"知识有序化"的分类装置，常承自已散佚的前人 doxography，被评 unscientific。
- **分账**：作"思想谱系事实"——正份额≈0、不可独立核、不作谱系承重；作"编者时代的观念史/学派自我认知样本"——高度可用。
- **禁回潮**：用途迁移不得把观念史样本重新当谱系事实引用（防许可证）。教材用"某人创立某派、某人师从某人"讲哲学史脉络，即是回潮。

## 五、载体/内容分离（carrier–content separation）★核心

不可靠二手载体中嵌入的一手文献（书信/遗嘱/法令/著作目录/残篇），其**真实性由文献自身内证＋真正的外部独立旁证决定，不由载体可信度决定**。"载体降解"对内容不加分也不减分。

**专属升格阀门（缺一不可，否则停留"相容待核"）**：
| 阀门 | 判据 |
|---|---|
| **V0 载体隔离** | 编者"不加批判"名声不进入嵌入文献真实性权重（零加权，不加分不减分） |
| **V1 内证** | 风格、术语一致、教义自洽；**只排除低水平伪造，不确证原件**（高明伪造也能咬合） |
| **V2 真正分叉旁证** | 独立转述链的载体（同时代他著、出土文献、铭文、译本）；但**只升"大纲/骨架"，不升"特定文献文本真伪"**——相容≠核对 |
| **V3 句级封顶** | 即便通过，封顶于"骨架/大纲"，不升"逐字原文"；可疑的弟子成分单独降级 |

- **标签落点**：通过 V0–V3 的嵌入文献＝"高度可能（骨架）"，**不是"已确认"**；"逐字原文"永远在骨架之下；有编纂痕迹的＝"永久部分待证"。
- **相容≠核对再次适用**：外部旁证印证的是教义生态/骨架真实，不证明"这一封特定文献就是当年那一封"。

## 六、囤积≠保真（反直觉修正）★核心

- **禁止**"不加批判所以忠实保存原貌"的直觉。拆两条正交轴：
  - **干预度**：不加批判＝低干预（未声明批判性改写）——但这只是"未经声明"，不是"经检验的原样"。
  - **污染度**：不加筛选＝**高污染**（异说/伪托/传奇/笑话一并进入），且原样性未经抄本链检验（共同祖先/缺尾/后代重编）。
- **收口**：囤积对"原样保存"命题＝**零正份额**，仅保留**弱否定**"未证成刻意系统性篡改"。保真度轴的正贡献是错误暗示，须撤回。
- 类比：囤积者是"原材料仓库"（真伪并存、不负责烹饪），筛选者是"成品菜肴"（信噪比高但注入厨师判断）；仓库之功在保存，不在保真。

## 七、多抄本≠多见证（stemma 单一祖先）

- 若现存抄本皆源自一共同祖先（可由共同缺漏/固定缺尾判定），则抄本数量**不增加见证独立性**——"多抄本互证"是幻觉（文本批评版的同源互证谬误）。
- 固定缺尾＝固定黑箱；后代统一的段落编号＝**人为标准化外观**，非原貌，不可当原文结构证据。

## 八、快速判据清单（Cheat Sheet）

| 遇到 | 判据 | 标签 |
|---|---|---|
| 编者逐条署名来源 | 来源可核？署名加权？ | 透明黑箱／零正份额 |
| 唯一来源、后世皆引用他 | 独立验证线在链外吗？ | n=1 幸存偏差 |
| 传承两分/师承链 | 谱系事实 or 观念史样本？ | 建构／禁回潮 |
| 嵌入书信/遗嘱/目录 | 过 V0–V3 了吗？升到骨架还是逐字？ | 载体/内容分离 |
| "不加批判所以忠实" | 干预≠保真，污染度如何？ | 囤积≠保真 |
| "他记载较正确" | 功劳归材料还是编者？ | 柔化句／功劳归属 |
| 多抄本皆缺同一段 | 共同祖先？ | 多抄本≠多见证 |

## 九、案例
