# 断代夹逼、引文极性反转与辨伪合围审查

> 适用场景：古籍/文本"是否某时代伪作"的断代辨伪，以及辨伪史本身（前人的辨伪论证）可靠性审查。
> 来源案例：《列子》是否魏晋伪书（2026-11-22，案例 `cases/liezi-wei-jin-redaction.md`，结论 `debates/conclusions/liezi-wei-jin-redaction.md`）。

## 一、断代夹逼（dating pincer）与取材方向条件化

### 核心
古代文本断代长期困于"文气像某时代"的印象式判断。断代夹逼提供一个**可被反例证伪的硬框架**：当文本被指认取材于某件年代可考的对象时，该对象的年代给出写定年代的 **terminus post quem（下限）**；结合另一可考事件给出 **terminus ante quem（上限）**，夹出窄写定窗口。

案例模板：
```text
《列子·汤问》机关木人 ≈ 竺法护译《生经》（太康六年 285 译出）
→ 若取材方向成立，成书不早于 285
《列子·周穆王》摄取汲冢书《穆天子传》（281 出土，束皙 281–285 整理）
→ 上限参考永嘉之乱（311）前后
→ 窗口 285–311（季羡林）
```

### 与既有"最早硬证据晚"的区别
| 框架 | 结构 | 可证伪性 |
|---|---|---|
| 最早硬证据远晚于声称起源 | 单向（只有下限） | 弱——补一个更早证据即松动 |
| 文气/风格印象 | 无锚 | 无——纯解释 |
| **断代夹逼** | **双向窗口，由可考事件锚定** | **强——一件反例文献即可推翻** |

### 方向与条件化（关键纪律）
"两文本相似"是**对称事实**，不构成方向证据。谁抄谁必须独立判断：
1. 方向若依赖"该文本是伪书"这一待证结论反推 → **循环论证**（用"列子伪"推"东传方向"，再用"东传方向"夹逼"列子伪"）。
2. 方向若依赖"某文化传播大方向"的背景推断（如佛教东传）→ 是**合理但非决定性**的独立支柱，须降为条件性结论。
3. 表述纪律：
   - ✅ "若取材方向成立，则写定不早于285；该方向为高度可能（约0.8），非已确认。"
   - ❌ "成书必在285–311年。"（把条件性结论伪装成铁证）
4. 概率是**序数量化**（证据政策层面的强度），非贝叶斯后验；禁止伪精确小数背后不独立的因子。

### 反例清单（夹逼失效条件）
- 一件早于下限、明确引用了"被认作后出段落"的独立文献 → 窗口塌。
- 取材方向反转（源头在自称伪书的一方）→ 窗口反向，文本反成源。

## 二、引文极性反转（citation polarity inversion）

### 定义
**移交转述系统性柔化**（下游把"撤回/证伪"软化为"修正"）的**极性升级子类**：不是弱化强度，而是**把权威的原意整个引反**，用反方权威为己方背书。

案例：杨伯峻《辨伪文字辑略》引朱熹《观列子偶书》作"《列子》剽窃佛书"的辨伪例证；而朱熹《语类》卷126原话是"《圆觉》……即是窃《列子》语"——**朱熹认为佛书窃《列子》，方向恰好相反**。同一段材料，被引反来支撑相反结论。

### 危害
- 制造**假的多数合围**：让权威站在它实际反对的一边。
- 在辨伪这种"靠证据聚合说话"的领域，污染的是合围的**方向基础**而非仅某一根柱子。

### 对策
1. **方向核对义务**：凡以"某某权威说X"支撑结论，必须回原文核对谓词方向（谁作用于谁、谁先谁后、肯定还是否定）。
2. **反转柱隔离**：确认反转后，该条证据出局（不计入合围），但**不过度外推**到"所有辨伪证据都不可信"——那是把一根坏柱夸大成整座危楼。
3. **与柔化的分级**：柔化＝强度衰减（撤回→修正）；极性反转＝方向颠倒；后者危害更高，触发强制核原文。

## 三、缺沉默当剪影（absence-as-survival）

### 定义
证据方向倒置的新子型：用"某故事不见于某时代他书"来论证"它是更早古本的遗存剪影"。

案例：以"愚公移山、扁鹊易心不见于汉魏诸书"论证"今本《列子》保存了先秦古本断简"。

### 为什么是倒置
"缺席于他书"这一沉默事实**同时兼容**两个相反假说：
- 假说A：故事来自先秦古本，他书未收；
- 假说B：故事是魏晋新创，他书自然没有。

沉默对 A、B **均为零份额**，不能给任何一方加权。把沉默读成 A 的证据，是把"无法区分"误当"支持其一"。

### 正确处理
- 来源标**方法性不可判**，移入不可知栏，不进正面结论。
- 本案推理者 M1 自我撤回即为示范：从"含先秦断简剪影"（正面断言）降为"来源不可判"。
- 区分：这与"古材料≠真篇章"（伪古文尚书案）不同——后者是确有可识别古句；本案是连"是否存在古材料"都不可判。

## 四、合围独立性折价（independence discount）

### 问题
辨伪常诉诸"百证合围"。但多条证据线若**共享同一隐含前提**，它们不是独立支柱，而是同一支柱的多个表现——合围强度被系统性高估。

### 核算方法
对每条证据线问："抽掉'文本后出/某结论成立'这个前提，这条证据还站得住吗？"
- 站得住 → 独立支柱（如：汉语史词汇断代只依赖语言演变；汲冢书出土年代是考古事实）。
- 需借助方向判断 → 半独立（如：文本比对＋"谁抄谁"）。
- 依赖待证结论反推 → 非独立／循环（如：用"伪"推方向再用方向证"伪"）。
- 已被证伪（引文反转）→ 出局。

本案折价结果：五证合围 → **两硬独立锚（语言史、汲冢书锚）＋两条半独立/条件性辅证＋一条出局**，整体从"铁证"降为"稳健的高度可能"，方向不变、强度下降。

## 五、可复用公式

```text
文本断代辨伪：
锁定写作对象 → 找可考事件锚（译经/出土/制度/避讳）→ 建双向窗口
→ 钉取材方向（查循环/查背景依赖）→ 方向条件化＋序数量化
→ 列反例失效条件

辨伪史审查：
逐条核权威引文方向（防极性反转）→ 反转柱隔离不出局外推
→ 核算各线独立性（抽前提测试）→ 合围折价 → 沉默证据归零（防缺沉默当剪影）
→ 分层收口（方向 vs 强度分开报）
```
