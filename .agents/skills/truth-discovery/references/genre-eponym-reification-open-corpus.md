# 体裁标签实体化与开放式语料库：无主口传体裁如何被压成"一个人的书"

> 适用：一个**无主口传短篇体裁**（寓言 fable、笑话、格言、谚语故事、成语故事）被归到一个名字下，大众把它压成"真实作者个人创作 vs 纯虚构民间故事集"二分。典型："伊索"与《伊索寓言》。
> 划界：
> - ≠ `cases/vyasa-mahabharata-authorship.md` / `valmiki-ramayana-authorship.md` / `homer-existence-bardic-collective.md`——那些是**长篇口传史诗＋单一层累定本**，名号是职称（vyāsa＝编排者）或荣誉品牌（ādi-kavi＝第一诗人）；本案是**短篇体裁＋开放式语料库**，名号是**体裁形容词＋描述性族裔/体征标签**。近证伪对象不同，禁匀质套用。
> - ≠ `secondhand-compiler-transmission-hub.md`——那是二手编者转引一手文献；本案无一手编者，是体裁长期无主累积后被追认作者。
> - ≠ `genre-grafting-composite-caricature.md`——那是喜剧把时代 profile 嫁接真人；本案是把体裁归名给一个可能虚构的创始人。

## 一、总原则：拆成正交双问，禁止互推

面对"X 是否真实存在？《X 集》是个人创作还是民间故事集？"这类题，先锁定这是**两个正交命题**：

- **问A（人物存在）**：是否有一个叫 X 的、与这种体裁有关的、可辨识的历史个体？
- **问B（文本归属）**：现存以 X 为名的集子，是否由 X 个人创作？

两条铁律：
- **存在传说核心 ≠ 现存集为一人作**（A 不推出 B）；
- **集体/多手创作 ≠ 人物从未存在**（¬B 不推出 ¬A）。

禁止"用一问吞另一问"：既不能用"B 是集体创作"论证"X 从未存在"，也不能用"A 大概存在"论证"集子是 X 写的"。这是与单命题归属案（姊妹典籍同作者、单书亲撰）的根本区别。

## 二、体裁标签实体化（genre-eponym reification）

一个无主体裁获得作者名，通常经三条叠加路径，须分层识别：

| 路径 | 机制 | 案例 | 升格权重 |
|---|---|---|---|
| 职称/通名→专名 | 功能标签被读作护照姓名 | vyāsa＝编排者 | 0 |
| 荣誉品牌→专名 | ādi-kavi／"第一诗人"式称号被读成履历 | 蚁垤 | 0 |
| **体裁形容词＋描述标签→专名** | logoi Aisopeioi（"伊索式话语"）是**形容词**指体裁；Aesop←Aithiop（埃塞俄比亚人）是**族裔/体征描述标签**，二者被实体化为作者专名 | 伊索 | 0 |

- **形容词证据判据**：当最早文献用"X 式（X-ian/X-is）"指**一类故事**而非"X 的作品"时，这是体裁名的强信号，对作者命题**零正份额**。希腊语 logoi Aisopeioi、英语 Aesopian fable 皆此类。
- **描述标签判据**：名字可溯源到普通描述词（族裔、体征、职业）时，它是**标签实体化的化石**，不是护照姓名；扣除语义后若无独立外证，人物层不得升格。
- **两个竞争解释**：(α) 真实讲述者→体裁得名；(β) 体裁需要一个作者名→反造创始人。"给无主体裁补一个权威作者名"是跨文化的普遍叙事冲动（Britannica："a name invented to provide an author for the fables"），故 **(β) 为主解释**；(α) 无法排除但**不可知、不加权**。
- **体裁锚的正确落点**：阿里斯托芬、柏拉图、亚里士多德都提"伊索式故事"——这是体裁名在前5—4世纪流通的**多源公共事实见证**（A级），对**人物层正份额＝0**。禁把"多个古典作家都提他"当人物独立验证线（他们提的是同一个体裁名）。

## 三、开放式语料库（open corpus）≠ 单一层累定本

这是本案与口传史诗圣作者案的核心分界，直接决定近证伪锁定句怎么写。

| 维度 | 单一层累定本（史诗案） | 开放式语料库（本案） |
|---|---|---|
| 对象 | 一部作品，边界闭合 | 一类故事的集合，**边界持续开放** |
| 生成 | 长时段层累、多手编定于一本 | 历代不断增补、跨文明汇入 |
| 校勘形态 | 批判校本重建"原文" | Perry Index **按最早出处分型分代**（stratigraphy by attestation） |
| 内部成分 | 主要是同一传统的沉积 | 异质：无主口传＋identifiable 文人原创＋跨文明共享＋后世增补 |
| 近证伪锁定句 | "单人写出现存层累成品" | "**单一历史个体独自写出全部开放语料库**" |

- **四成分分账**：以《伊索寓言》为例——①无主口传民间故事（多数古则，故事类型跨国流通）；②**可辨识文人原创**（Phaedrus、Babrius 自述或明载的新则——这部分恰恰**不是**民间故事）；③近东/印度共享故事（与《五卷书》《Jataka》重合十余则）；④中世纪修道院与近代印刷增补。故"民间故事集"标签**只描述第①层**，作整库标签＝过度简化。
- **禁"层累＝定本"迁移**：不要把史诗案的"层累多手→单人写出现存本近证伪"原样搬来；本案没有"现存本"这个闭合对象，只有持续开放的语料集合。

## 四、本典内部反证（internal counter-testimony）

- 定义：**被归名传统自身的经典文本之一**，说出与归名叙事相矛盾的话。例：Babrius（"伊索寓言"传统的希腊韵文经典作者）自序称寓言是**叙利亚人（Ninos/Belos 时代）的发明**——这是"希腊开创者"品牌内部的裂痕。
- 与"接受史切除方法声明"的反向关系：那里是作者方法限制被后世切除（正面圣典化）；这里是**归名经典自己保留了反证**，但同样被接受史忽略。二者都是"文本内证据 vs 后世包装"的张力，方向相反。
- 证据力：本典内部反证对"品牌叙事"是强反证（自己人拆台），但对"体裁起源地"只作相容线索（Babrius 也可能是套用近东起源的文学套语），不单独定案。

## 五、跨文明来源与品牌降格

- 短篇动物寓言普遍**早于**希腊、跨文明分布（苏美尔/阿卡德早一两千年；印度《五卷书》；中国、非洲）。归到一人名下的"开创者"叙事，实为**希腊中心主义品牌扩张**——与"希腊奇迹独立起源"同构，只是对象从哲学/科学换成寓言。
- 收口：把"X 开创某体裁"降为"**X 是某传统（希腊—罗马寓言）的名义焦点与品牌总名**"，不否认该传统的真实贡献，也不回赠全球开创权。
- 来源方向常无定论（Perry 反对希腊直接源自印度，主张最早见于希腊/近东者后见于印度）——标"跨文明累积／交流圈"，拒绝站队"谁抄谁"。

## 六、流通禁令

1. 禁"真实 X 个人创作了《X 集》"——人物弱于护照＋个人创作近证伪，双重过度宣称。
2. 禁"X 纯属虚构、从未有人"——反向过度宣称；保留合理待证的弱核心。
3. 禁"《X 集》是民间故事集"作整库标签——须用"开放式语料库"，并点明库内文人原创层。
4. 禁把体裁锚（多作家都提 X）当人物独立验证线——对人物层零正份额。
5. 禁描述标签（族裔/体征/职称）→人物存在加分——升格权重≈0。
6. 禁"X 开创世界/西方某体裁"——降为传统名义焦点＋标注中心主义包装。
7. 禁匀质套用史诗"单人现存层累成品近证伪"模板——对象类型（短篇开放语料库 vs 长篇定本）须先钉死。
8. 人物判断流通须带"弱于护照已证／疑似体裁拟人化"，省略即柔化。

## 七、判断标签

体裁标签实体化（genre-eponym reification）／开放式语料库（open corpus）／本典内部反证／跨文明累积／品牌化／希腊中心主义包装／合理待证·弱于护照／近证伪·过度宣称（个人创作命题）／零正份额（体裁锚对人物层）
