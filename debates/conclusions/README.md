## 判断标签说明

| 标签 | 含义 |
|---|---|
| 已确认 | 多源独立验证，S/A级证据充分 |
| 高度可能 | 证据链完整，虽有缺口但整体可信 |
| 合理 | 证据有限但逻辑自洽 |
| 待证 | 现有证据不足以判断 |
| 永久待证 | 证据被销毁，间接证据不足 |
| 过度宣称 | 宣称强度远超证据支撑 |
| 归属错误 | 明确不属于声称的归属 |
| 品牌化 | 后世将混合/被操纵的材料归到权威名字下 |
| 已证伪 | 有明确反证 |
| 累积发明 | 多人长期接力贡献 |
| 双极品牌化 | 同一对象被两权威冠相反称号且各自制度化；各品牌不同层则分层兼容 |
| 分层混合对象 | 对象不同层可信度不一，须逐层判断而非整体真伪裁决 |
| 张力元文本 | 作者自述方法论因内部张力不可从文本 alone 量化，仅记意图声明，不可作保真证书 |
| 代言式文学重构 | 史家以历史人物口吻撰写载言成品；骨架可高、措辞近证伪、论旨无正份额；成品作者性归书写者 |
| 道德塑形 | 德行主题选材／示范已确认；≠寓言全虚构；降级寓言标签后禁止回赠史料信用 |
| 设计污染 | 强制配对／比较终裁对叙事与胜负的系统性偏置；终裁层保真正贡献＝0 |
| 零正份额 | 对事件史禁止赋正权重（含「谨慎可用／低置信引用」）；待证≠部分信用 |
| 声誉史 | 谣言／丑闻作声誉／主题／接受史高度可用；不回流事件史 |
| 理想类型 / 时代话语表征（可选下游） | 非主结论；归属不可核后可另账作时代话语/作者思想样本；禁回潮弱可推断／大意弱真实 |
