## 一、简短判断

这是一个被「史料／八卦」二分压平的**主题式帝王轶事—类型学 bios 工程**，无法用真假或整书站队裁决。核心结论：**拒斥二元**；*ab epistulis*＝制度可能光环，**非**档案通行证；rubrics＝**已确认**主题优选装置；**私密轶事对事件史＝默认／未抽样则固定零正份额**；文书强制 **(a)/(b) 分裁**（引用≠亲见）；公开骨架＝**相容待核／个案升格**，升格阀门 **V0–V3 默认关闭**；**残暴谓词隔离**（禁丑闻簇洗入层 3）；**声誉史可用不回流**事件史；「罗马八卦之父」↔「十二凯撒信史」＝**双重品牌过度宣称**。整体最可能解释＝以**已升格窄公开坐标**为锚（相容≠锚）、经 rubrics 装填与宫廷—元老谣言／死后形象政治完成的轶事库——**不是**无过滤宫廷信史，**也不是**全书垃圾八卦。本轮核心成果是推理者两轮合计 **M1–M17**（含阀门、谓词隔离、禁柔化句、最小抽样），质疑者结案确认残值通道已挖断、无新问题。

## 四、知识谱系

- **前置条件（体裁／语料库层）**：罗马帝王传／轶事传统、元老—骑士舆论与死后形象政治、修辞化「好帝／暴君」类型学，为 *Caesares* 提供材料与装填语法；苏氏常呈「他写信说／据说」句式，底本与保管链多不可复原。
- **同代／近源验证上限**：Tacitus／Dio 与苏氏「可对照」**默认**＝同生态互见／共享谣言—修辞库，**不作** alone 独立核验；真正分叉优先看铭文、钱币、考古、当事人／公共纪念文书，且只升格窄公开坐标／文书大意。
- **制度身份节点**：*ab epistulis* 完成「接近文书系统的制度可能」叙述；正文极少显式「我从皇档抄出 X」→ **(b) 已实现保真／保管链未证成**；职位对升格权重＝0。
- **体裁节点**：rubrics 结构完成主题优选装置确认；无同等显式「合性格压年表」吸烟枪，结构推定已够——装置确认 ≠ 全书伪造。
- **后续承接**：古典学内部接近「批判使用＋体裁自觉」；大众／影视市场并行「信史生动细节」与「八卦经典」，常切除 rubrics 与 *fertur* 等认知情态标记。
- **断裂点与黑箱**：①职位时序与失宠后调档权古代硬句稀疏；②*fertur* 等在好帝／坏帝传的量化分布待证；③双重品牌接受史切除节点编年待专题；④隐性比较篇幅／省略样本不足 → 维持待证偏置假说；⑤发明／优选／传统回响在不可核处常不可分（对事件史正份额仍均为 0）。

## 七、分层结论

**归属阶梯判断**

- **人物层**：苏埃托尼乌斯与 *De vita Caesarum*——**高度可能／锚定成立**；*ab epistulis* 高度可能但**非**保管链／升格权重。
- **体裁／方法层**：主题 rubrics——**已确认**优选装置；非编年正史。
- **事件坐标层（公开骨架）**：**相容待核／个案升格**；V0–V3 默认关闭；锚＝仅已升格窄坐标。
- **文书层**：(a) 公共文书回声——相容待核／可走阀门；(b) 私人文书／对话道具——**事件史零正份额**。
- **私密轶事层**：事件史——**过度宣称／默认零正份额**；永久部分待证 ≠ 部分信用。
- **声誉层**：谣言／死后形象政治——**高度可用**；**不回流**事件史。
- **属性／刻板层**：「变态暴君」等——**高可疑／禁洗入骨架**。
- **品牌／神话层**：「八卦之父」「信史宝库」——**双重品牌化／过度宣称已确认**。

**整体最可能解释（结构假说）**：苏埃托尼乌斯以真实作者身份与帝国官僚接近度（不可计价光环）书写主题式帝王轶事库；公开政治—建筑—法令坐标可与铭文／他史相容，但互见默认同池，升格须过 V0–V3；私密丑闻与不可核「他写道」对事件重建关闭正份额，主用途为声誉史、主题学与接受史。近代接受史同时把它当作信史宝库与八卦经典，系统性淡化 rubrics 与谣言标记，形成互相续命的双重品牌。拒斥「史料 vs 八卦」假二分；亦拒斥用「分层可用／宜谨慎」舒适壳买回丑闻事件史信用。

- **最大不确定性来源**：①私密轶事生成假说不可分；②同池互见中真正分叉比例不可精确估计；③*ab epistulis* 时序与调档权硬句；④*fertur* 分布与接受史切除节点编年。
- **隐匿评估**：主隐匿在**接受史与方法**——rubrics／谣言标记被切除、史料／八卦二分替代中间地带、边缘印证外推核心丑闻、职位光环与「谨慎可用」偷渡——而非湮灭全部公共坐标。**可知**：体裁装置、轶事事件史不可用、文书分裁、阀门与包装机制、引用边界；**不可确证**：多数私密轶事是否「曾发生」、区块级骨架独立比例、丑闻簇「真实坏程度」先验。
- **什么新证据可以改变结论**：近同时代真正分叉（铭文／非同池传统／当事人文书）在**具体轶事论旨结构**上收敛 → 可个案重开该条正份额（仍句级封顶）；更多分叉审计 → 可扩骨架／文书 (a) 白名单（仍不回流 (b)／私密）；古代硬句钉死职位—撰作窗口 → 微调层 1 时序，**不**回赠丑闻份额；量化 *fertur* 分布若显示系统抹平 → 强化包装层，不改变零正份额纪律。

## 九、判断标签

对各层精确标注：

- 人物／著作 → **高度可能／已锚定**
- *ab epistulis* → **制度可能／光环**（升格零加权；≠保管链）
- rubrics 体裁 → **已确认**（主题优选装置）
- 公开骨架 → **相容待核／个案升格**（阀门默认关闭）
- 文书 (a) → **相容待核**（禁职位加权）
- 文书 (b)／私密轶事（事件史） → **过度宣称／零正份额**
- 声誉／谣言 → **高度可用（声誉史）**；回流事件史 → **禁止**
- 「残暴／失政」未升格谓词 → **属性／层 5；禁层 3 承重**
- 隐性比较装置 → **待证偏置假说**
- 「八卦」「信史」整书标签 → **双重品牌化／过度宣称／已确认**
- 整体定性 → **帝王轶事—类型学 bios 工程（结构假说）**；假二分降级

**标签**：高度可能 / 已确认 / 过度宣称 / 相容待核 / 个案升格 / 零正份额 / 双重品牌化 / 声誉史 / 谓词隔离 / 结构假说  
**整体可信度**：中高（分层严重不均；上限受骨架独立性未证与轶事零配额约束）  
**方法论提取**：职位光环 ≠ 保管链／升格权重；rubrics 主题优选 → 轶事事件史零正份额（待证≠部分信用）；文书 (a)/(b) 分裁（引用≠亲见）；升格阀门 V0–V3 默认关闭；残暴谓词隔离防洗钱链；声誉史不回流；相容≠锚；禁柔化句防「谨慎可用」翻译；同源互证／相容≠核对；双重品牌互相供养与接受史切除元结构；与普鲁塔克案同族、无 Synkrisis 但有待证隐性类型对照。
