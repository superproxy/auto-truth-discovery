# 求真辨伪报告：维特鲁威《建筑十书》是否确为一人所作？

## 一、简短判断

"确为一人所作"是一个把**人数、执笔方式、文本纯度**捆在一起的复合谓词，二元回答（是/否）本身非法。可确认的是：约公元前 1 世纪末，该书由一位被称作维特鲁威的罗马工程师**统筹写定、素材大量编译自希腊前人（尤重 Hermogenes）**；"纯逐字自撰"是过度宣称，"多人合著/伪书"无证据。收口为——**一人统筹的编译性技术著作，人物弱于护照、执笔人数待证、现存本非原貌**；整体置信度 0.86（针对框架，非任何单问答案）。

## 四、知识谱系

- **前置条件**：希腊化建筑理论（Hermogenes 的柱式与比例著作，今佚）、罗马工程实践（混凝土、供水、军用机械）、希腊数学/天文/医学知识池——此为**材料来源谱系**，不等于作者人数谱系。
- **同代验证**：Pliny 同时代稍晚提及、献辞对象奥古斯都——锚名号与时代，不锚逐字执笔。
- **后续承接**：中世纪抄本→文艺复兴人文主义校勘→历代建筑理论（Alberti、Palladio）→现代建筑史经典化，链条连续、无传承断裂黑箱。
- **断裂点/黑箱**：原始插图全佚（改由文本描述重建）；维特鲁威生平细节几乎全出自本书自身（自述循环）；全名两部分均无独立确证。**均属方法性不可得，非人为销毁式隐匿。**

## 六、辩论质量评估

- **质疑者最强论点（Top 3）**：①复合谓词未分解（人数⊥执笔⊥纯度）；②来源多元≠多人执笔的双向偷换；③"高度可能"立于名号归属一致这一弱正面证据上——成功逼出 M3 降级。
- **推理者最强辩护（Top 3）**：①三问分解框架；②双向对称不传递（来源多元≠多人执笔、一人执笔≠材料纯自创）；③"无 β 硬证=弱否定非正面证据"的举证责任纪律。
- **推理者修正的立场（本轮核心成果）**：**M1**（新轴→判据簇，抽掉测试）／**M2**（对象收窄到可归名原初写定层）／**M3**（一人统筹由"高度可能"降为"合理（偏弱）"）／**M4**（异质性给最强解释、明标非核对）。均为教科书级自我修正。
- **双方均承认的不确定性**：执笔人数无法用现存证据判定（β 多手增补既未证也未证伪）；维特鲁威其人"弱于护照"。
- **未解决的争议点**：无实质争议；仅 disjointed 的方向性解释强度为"最强解释"而非核对，已如实标注。

## 七、分层结论（归属阶梯）

整体落点：**由一位弱于护照的罗马工程师统筹写定、大量编译希腊前人材料、经历可分离后世编辑层的编译性技术著作**。

- 人物层 → 合理（弱于护照），全名待证。
- 编订层 → 一人统筹编纂，合理（偏弱）；纯逐字自撰=过度宣称。
- 改写层 → 现存本非原貌（插图/校勘/印本层），对作者性零正份额。
- 品牌层 → 双向品牌化（正面加冕 vs 伪史论反向加冕）。
- **对"确为一人所作"的直接回答**：三问分别定性——人数**待证**、执笔**编译性编纂高度可能（纯自撰过度宣称）**、纯度**非原貌已确认**；不存在一个统一的"是/否"。

## 八、置信度与不确定性

- **整体置信度 0.86（针对框架）**：三问分解 + 双向不传递 + 证据强度诚实降级的框架是稳健的；不针对"确为一人所作"这一被拒的二元答案。
- **最大不确定性来源**：执笔人数的正面证据缺失——只有名号归属一致（B）与文本自我呈现（A，不发证书），无同时代独立旁证能锚"一人执笔"。
- **什么新证据可改变结论**：若发现古代目录/同时代书信明确记载多人参与（如"某助手共撰第 X 卷"），可将"人数"从待证推向 β；若发现原初写定手稿能证全卷一人笔迹，可将"一人统筹"从合理升为高度可能。两者目前均无。
