# 步骤 8: optimizer_skill_review（沉淀审查）

## Skill 沉淀审查（并行子步）

### 1. 方法论增量评估

| 增量 | 类型 | 说明 |
|---|---|---|
| **嫁接拼贴（genre grafting / composite caricature）** | 新证据模式+新裁判规则 | 真实个人被体裁当作一股思想/潮流的具象载体：嫁接元素可归溯独立源头（阿那克萨戈拉存货、智者 topos）→ 对传主"现时立场"正份额 0；模板错挂与传主强身份标识矛盾=模板套用的自证。与"道德塑形/轶事优选"机制不同：拼贴公开场合、亲历者可同在场——禁匀质套近证伪/塑形模板 |
| **辩护性回响（apologetic echo）** | 新证据模式 | 敌意体裁先行流通后，辩护方写作"承认无损细节+否认有损指控"——其呼应不构成独立观察线；自指参照系（《会饮》215b 以喜剧形象为参照）是回响的文本内证据。同类于"同源互证谬误"的下游变体 |
| **同池回声生态** | 现有"同源互证"的生态级扩展 | 同一体裁生态内多部作品讽刺同一对象（《云》《Konnos》《蛙》互仿互指）=生态内持续性证据，非独立异常连乘 |
| **讽刺→损害→制度因果链** | 新裁判规则 | 接受链三档：受害者自述知晓损害（相容待核）/ 主因宣称（待证/过度宣称）/ 份额比例（永久不可知）；拒绝伪精确 |
| **用途分账正面案例** | 主干应用 | "歪曲"假二分拒斥：产物既非变形记录亦非忠实夸张——用途分账（公众认知镜像 vs 传主史料）替代二元裁决 |
