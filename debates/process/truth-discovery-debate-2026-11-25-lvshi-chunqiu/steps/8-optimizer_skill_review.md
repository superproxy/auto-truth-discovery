## 一、方法论增量评估

**是否产生新方法论洞察：是（高价值）。**

本案是现有案例库未覆盖的**全新机制**：所有已结案子书辨伪案的主轴都是"某人是否真作／是否伪书"（人物真伪、定本真伪、材料断代），而本案人物确定、文本归属确定，争点从"真伪"迁移到**"贡献份额可分配性"**。这是一条与"反伪精确"主线（《尔雅》解决≠选作者、鬼谷子三不可锚）平行的**第三个变体——份额版假任务**。

| 增量类型 | 具体内容 |
|---|---|
| **新归属模式（核心）** | **份额分配假任务（share-allocation pseudo-task）**：当集体编纂无分工记录、无可加总单位时，"某人贡献几何"是非法提问——不是"数据不足"而是"计量单位不存在"，比"待证"更强，直接判命题无效。替代方案＝职能层分解（发起/资助/组织/裁定/执笔/署名/包装逐层归属、逐层定级），禁止把多层重折为单一百分比 |
| **新归属模式** | **主编主持的协作生态写定本**：归属阶梯的新落点——人物确定＋文本归属确定，但作者性分布在协作生态与编订层；既非单作者、亦非无主语料库（伊索型） |
| **新红旗信号** | **双向品牌化（署名膨胀 vs 署名抹除互相续命）**：一端"全书皆主编一人智慧"、一端"主编固无与也"，两端受质疑时互相搬出当纠正，压平中间协作生态（与《史记》《汉志》原始"辑/作"分判相悖） |
| **新红旗信号** | **书名态三分偷换**：《吕氏春秋》（姓氏冠名＋史典自号）／《吕览》（体例简称）／《吕子》（诸子升格＝二次品牌化）对应三种不同署名机制，压成一层即对象偷换 |
| **新证据模式** | **意图声明三层切割在主编场景的变体**：主编序（《序意》）只锚 (a) 意图声明；本案张力不是"保真 vs 裁量"（史家拟辞型）而是"主编为集体作品立纲领"——纲领证裁定意图，不证逐篇执笔；且纲领语义（方法论准则 vs 单一思想纲领）决定 (b) 判词 |
| **方法论修正** | **证据等级通胀＋同源互证折价**：《史记》《汉志》皆为 B 且极可能同源，《汉志》"辑智略士作"据《史记》转化——时间更晚者不增独立性，"双证"折为单柱 B（质疑者促成 M1） |
| **方法论修正** | **同义反复冒充实质命题**："书有篇数→存在统一编排控制者"是同义反复；整齐兼容秦相府设计/汉代整理标准化/传抄自然规整三路径，控制者身份不可定（M2） |
| **方法论修正** | **multipolar 两问分层**：编选取向存在（合理）≠ 单一思想主旨存在（近证伪）；四派各引文本各有依据，裁判不站队（M4） |
| **方法论修正** | **锚点多解伪精确**：同一 A 级锚（"维秦八年岁在涒滩"）因历法换算规则不同产出多解，规则本身不可考→给窗口（前 241–前 239）＋单一年份永久待证，禁任一派站队 |
| **方法论修正** | **材料外溢→反向重塑**：《月令》被《礼记》采入（方向可定稀有锚）→ 反过来催生后世以经部标准重排本书篇序——"材料外溢→篇序反向改造"链（M6） |
| **方法论修正** | **四条对称不传递**：本案版①资助/组织≠执笔②裁定意图≠全书贯彻③主编署名≠思想独归④门客执笔≠主编无思想贡献——前三条向下切、第四条补反向，双向对称防两端 |
